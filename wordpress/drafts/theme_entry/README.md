# テーマ入口記事ドラフト

作成日: 2026-05-22

トップページMVPの `テーマから探す` 導線を育てるための常設型テーマ記事。

## ドラフト一覧

1. `interest-rate-impact-stocks.html`
   - 金利上昇で見る企業影響
   - 銀行、不動産、リース、保険、成長株、設備投資企業への橋渡し

2. `fx-impact-company-earnings.html`
   - 為替で業績が動く企業の見方
   - 輸出、輸入、海外売上、原材料輸入企業への橋渡し

3. `raw-material-cost-pass-through.html`
   - 原材料高と価格転嫁
   - 食品、化学、紙、建材、金属加工、小売への橋渡し

4. `semiconductor-investment-supply-chain.html`
   - 半導体投資の波及先
   - 装置、部材、電力、建設、空調、物流、不動産への橋渡し

5. `policy-subsidy-investment-theme.html`
   - 政策・補助金テーマの読み方
   - 政策、補助金、規制、公共投資を受注・売上・利益へつなぐ橋渡し

6. `energy-transition-power-investment.html`
   - エネルギー転換と電力投資
   - 電力、送配電、蓄電、重電、電線、建設、空調への橋渡し

7. `labor-shortage-automation-investment.html`
   - 人手不足と省力化投資
   - 外食、小売、物流、建設、製造、省力化機械、IT、ロボットへの橋渡し

8. `price-hike-consumer-demand.html`
   - 値上げと消費者需要
   - 外食、小売、食品、日用品、サービスの単価・数量・利益率への橋渡し

9. `inbound-demand-company-impact.html`
   - インバウンド需要の読み方
   - 百貨店、免税、小売、ホテル、鉄道、外食、空港関連への橋渡し

10. `defense-security-investment-theme.html`
    - 防衛・安全保障投資の読み方
    - 防衛費、装備品、部材、造船、航空、通信、IT、宇宙関連への橋渡し

11. `logistics-reform-2024-problem.html`
    - 物流改革と2024年問題
    - 運輸、倉庫、小売、製造、EC、物流自動化、配送管理ITへの橋渡し

## 公開時の想定カテゴリ

- テーマの読み方

## アイキャッチ

記事別アイキャッチは `wordpress/assets/eyecatch/theme-reading/articles/` に作成済み。

共通ルール:

- 1200x630
- 黒ベース、黄色アクセント、白ロゴ
- カテゴリ表記は `テーマの読み方` の黄色文字＋下線
- 記事タイトルは短くし、詳細はWordPress投稿タイトル側で補う

## 公開前チェック

- タイトル、スラッグ、カテゴリをWordPress側で設定する
- `<h1>` は本文に含めず、WordPress投稿タイトルとして設定する
- 投資助言ではない注意書きを残す
- 関連する企業分析記事がある場合は、公開後に内部リンクを追加する
- 最新ニュース記事ではなく常設の入口記事として使える表現にする
