# 基礎講座 初期記事ドラフト

作成日: 2026-05-22

トップページMVPの「投資の読み方」導線を空欄にしないための初期記事。

## ドラフト一覧

1. `kessan-tanshin-reading-guide.html`
   - 決算短信の読み方
   - 企業分析記事へ入る前の基本導線

2. `operating-margin-guide.html`
   - 営業利益率の見方
   - 売上と利益の違い、価格転嫁、固定費、ミックス改善への入口

3. `orders-backlog-inventory-guide.html`
   - 受注残と在庫の見方
   - 製造業・建設・半導体・小売分析への橋渡し

4. `roe-roic-guide.html`
   - ROEとROICの違い
   - 自己資本の効率、事業の稼ぐ力、財務リスクへの橋渡し

5. `segment-information-guide.html`
   - セグメント情報の読み方
   - 事業別の売上、利益率、構成比、次に見るKPIへの橋渡し

6. `cash-flow-guide.html`
   - キャッシュフロー計算書の見方
   - 利益と現金のズレ、投資余力、財務リスクへの橋渡し

7. `medium-term-plan-guide.html`
   - 中期経営計画の見方
   - 会社計画の前提、達成条件、反証KPIへの橋渡し

8. `price-pass-through-guide.html`
   - 価格転嫁とは何か
   - コスト増、値上げ、数量、利益率への橋渡し

9. `earnings-progress-rate-guide.html`
   - 進捗率の見方
   - 会社予想、季節性、上方修正・下方修正への橋渡し

10. `goodwill-impairment-guide.html`
    - のれんと減損の見方
    - M&A、買収後の利益貢献、減損リスクへの橋渡し

11. `payout-ratio-total-return-guide.html`
    - 配当性向と総還元性向の見方
    - 配当、自社株買い、DOE、還元余力への橋渡し

12. `equity-ratio-interest-bearing-debt-guide.html`
    - 自己資本比率と有利子負債の見方
    - 財務安全性、借入、金利負担、返済余力への橋渡し
