【財務テーブルの厳密転記ルール（最重要）】
- 財務テーブルでは、行ラベルと数値を1対1で対応させて転記すること
- `売上高` `売上総利益` `営業利益` `経常利益` `当期純利益` `販管費` などの基本項目は、必ず同一行の数値だけを採用すること
- 近くにある別行の数値を補完して結びつけることは禁止
- `売上高` と `売上総利益` が両方ある資料では、必ず別項目として保持し、混同しないこと
- 横並びの財務表では、列見出し（例：`2025年3月期` `2026年3月期` `A` `B` `前期` `当期`）と各数値の対応を厳密に固定すること
- 左から右へ並ぶ比較表について、左列を前年・右列を当年として機械的に並べ替えないこと。必ず表頭の年度・期間ラベルを確認してから転記すること
- `2025年3月期 282 / 2026年3月期 216` のような横並び数値は、行ラベルだけでなく列見出しもセットで読み取り、年度を逆転させないこと
- 財務表を転記する際は、最低でも `売上高` `売上総利益` `営業利益` `経常利益` `当期純利益` の5行について、各年度の値を列見出しつきで確認すること
- 年度や四半期の列対応に自信が持てない場合は、誤って前年・当年を入れ替えるより `年度列の対応要確認` と明記すること
- 表の崩れやOCR乱れで行ラベルと数値の対応に自信が持てない場合は、無理に埋めず `表の対応崩れのため要確認` と記載すること
- 単純差額で営業利益等と一致しない場合、無理に整合させず `定義要確認` と記載すること
- 単体・連結・国内のみ・全体・参考値など、前提の異なる数値を同じ表の同じ列に混在させないこと
- 同じ業績表の中に `確定値` と `参考値` を混在させる場合は、表に無理に入れず本文注記へ分離すること
- `2026年3月期は単体、2025年3月期は連結参考値` のように比較前提が異なる場合は、同一フォーマットの時系列表に並べるより、差異を明記した箇条書きまたは注記で整理すること
- 連結/単体、国内/全体、会社実績/参考値の別は、数値の直後または注記で必ず明示すること
- 横並びの複数図表がある場合は、必ず各図表のタイトルを先に固定し、`Sales by Segment` の数値を `Sales by Region` に流用しないこと
- 積み上げ棒グラフは、色と凡例の対応を確認してから項目別数値を読むこと。見た目の左右順だけで項目名を割り当てないこと
- 図表から読み取った内訳値は、可能な限り合計値との足し算一致を確認すること。一致しない場合は、無理に確定値化せず `図表読み取り要確認` と記載すること
- `その他` などの小区分が図中で個別に読み取れない場合、0と断定せず `未開示` `図中で個別値確認不可` のいずれかで残すこと

【年度ラベル・四半期ラベルの対応手順（最重要）】
- FY/年度/◯月期は、禁止例を個別に当てはめるのではなく、必ず次の順で判断すること
  1. 資料内から会社の決算月を確定する
  2. 資料内に明示された会計期間（例：`2025年4月〜2026年3月`）を最優先で採用する
  3. その会計期間に対応する `FYxx` `◯年度` `◯年◯月期` を1回だけ対応づける
  4. その対応を本文・表・用語定義のすべてに使い回す
- FYラベルは会社ごとの決算月に応じて解釈すること。3月決算だけを前提にしないこと
- 例：
  - 3月決算会社では `FY25 = 2025年4月〜2026年3月 = 2026年3月期`
  - 12月決算会社では `FY25 = 2025年1月〜2025年12月 = 2025年12月期`
  - 6月決算会社では `FY25 = 2024年7月〜2025年6月 = 2025年6月期`
- `FY25 = 2025年3月期` `FY26 = 2026年3月期` のような1年ずれは、3月決算会社に限らず「資料内の会計期間と不一致なFY対応」として禁止
- 四半期を併記する場合は、上で確定したFY対応から逆算し、`FY25 Q4 = 2026年1〜3月` のように月範囲まで一致させること
- 同一出力内で FY 対応が1か所でも揺れた場合は、FYラベル付きの断定をやめて `FYラベル要確認` とすること
- `3行サマリー` `業績推移` `ガイダンス・業績修正` `用語定義・単位注記` の4か所で FY 対応が完全一致していることを出力直前に再確認すること

【通期・四半期・構成比の分離ルール（最重要）】
- 次の4種類は別概念として整理し、同じ数値カテゴリとして混在させないこと
  - 通期実績
  - 四半期単独実績
  - 四半期時点の構成比
  - 現地通貨ベースの前年比伸び率
- `海外売上比率65.7%` のような数値が `4Q時点` の構成比で示されている場合、通期の地域売上比率として書かないこと
- 3行サマリーで4Q時点の構成比を使う場合は、必ず `2025年度4Q時点` `四半期末時点` などの時点を同じ文に残すこと
- 地域別・業種別の構成比に `4Q時点` `現地通貨ベース` `海外内比率` などの条件がある場合は、その条件を数値とセットで残すこと
- 現地通貨ベースの前年比伸び率を、円ベースの売上成長率として言い換えないこと
- 四半期単独の粗利率・販管費率・営業利益率を、通期比率として要約しないこと
- `海外売上比率は65.7%に達し` のように、4Q時点構成比を通期の確定比率に見せる3行サマリーは禁止。時点を同じ文に必ず残すこと
- 地域別または業種別の構成比が `日本・海外とも同一` と資料に明示されていない限り、日本向け構成比と海外向け構成比を同一値として展開しないこと
- 資料が業種別の全社構成比しか示していない場合、`日本10%、海外10%` のような地域別への再配分は禁止
- 業種別構成比について出典が `4Q時点` `下期` `現地通貨ベース` のいずれかである場合、見出しにもその粒度を残し、勝手に `通期` や `日本/海外別の確定構成比` に言い換えないこと
- 顧客基盤に関する `約35万社` `約35万拠点` `約11万社` などの数値は、社数・拠点数・国数を別概念として扱うこと。一次資料で `拠点` と書かれている数値を `社` に書き換えないこと
- 通期ガイダンスの記載がない場合は、`資料内に通期ガイダンスの記載なし` と記載すること。`最新ガイダンス相当` `実績値がガイダンス代わり` などの要約は禁止

【単位処理ルール（最重要）】
- まず表や見出しの単位表記を確認すること
- 単位が確認できる場合のみ、日本語の単位へ変換してよい
- 単位が曖昧な場合は、原資料の数値を保持し「原資料表記」「単位要確認」を付けること
- 単位が曖昧な数値について、「130億円」と書いた後に別の箇所で「1,300億円の可能性」と揺らすことは禁止
- 「百万円」単位をそのまま「億円」と誤読しないこと
- 根拠のない補完推計で過年度数値を埋めないこと
- 出力開始時に、今回の要約を `億円` で書くのか `10億円単位` で書くのかを内部的に1つ決め、その後は本文・表・注記・ガイダンス・市場規模説明のすべてで同じ単位系を維持すること
- `単位：10億円` を採用した場合、本文で `1,128.6億円` `499.1億円` のように `10億円値+億円ラベル` を書くことは禁止
- `億円` を採用した場合は、`1,128.6` のような `10億円単位の元値` をそのまま使わず、必ず `×10` して `1兆1,286億円` のように変換すること
- `JPY B` は `10億円単位` を意味するため、`億円（JPY B）` のような併記は禁止
- 同一出力内で `単位：10億円` としながら、一部の表や箇条書きだけ `億円` へ切り替えることは禁止
- 日本円建ての主要財務数値（売上高、営業利益、当期利益、会社予想、セグメント売上など）は、原資料で単位が確認できる場合に限り、この段階で選んだ主表示単位へ早めに一括変換して固定してよい
- ただし、`USD` `円/株` `%` `pt` `倍` `件` などは別単位として扱い、主表示単位へ寄せて変換しないこと
- 外部市場規模や市況指標が `USD` 建ての場合は、原則として `USD` のまま保持し、`USD→円→億円` の試算は必要な場面だけに限定すること
- `×10` の換算は `billion yen` `JPY B` `10億円` など日本円の単位にだけ適用し、`USD` `億USD` `million USD` には適用しないこと
- 原資料がすでに `69億USD` `87〜95億USD` のように日本語で整理されている場合、その数値へさらに `×10` を掛けて `690億USD` `870〜950億USD` に書き換えることは禁止
- 同じ指標について、工程途中で `10億円表記` と `億円表記` を往復させないこと。いったん選んだ主表示単位へ固定したら、その後の要約内では再変換しないこと
- `増減額` `前年差` `予想差` の列だけ単位ラベルを `億円` に変えることは禁止。親表の単位と同じ単位で書くこと
- 単位が `10億円単位` の場合、本文中の `1,128.6億円` `499.1億円` `87〜95億ドル` のような表記は禁止。`1,128.6（10億円）` `87〜95億USD` のように元単位を維持すること
- PDF要約では、後段で使う主表示単位が明確な場合、日本円建ての主要財務数値だけはその単位へそろえてよいが、単位が曖昧な数値や個別単位付き数値まで一律変換しないこと
- `単位：10億円` を選んだ場合、3行サマリー・企業概要・ガイダンス・市場環境でも同じ単位を維持し、1か所でも `億円` ラベルを混在させないこと
- 単位注記の文言は `単位：10億円` または `数値単位：10億円` を基本形とし、`10億円単位で表示` `10億円単位の1,128.6` のような不自然な説明調の書き方は避けること

【資料範囲の厳守ルール（最重要）】
- 今回与えられたIR資料に書かれている内容だけを整理すること
- 中期経営計画資料の要約であれば、中計資料にない過年度実績や四半期実績を勝手に補完しないこと
- 統合報告書の要約であれば、統合報告書にない決算数値や四半期数値を勝手に補完しないこと
- 別資料にありそうでも、今回の入力テキスト内で確認できない内容は書かないこと
- 「業界的にありそう」「文脈上そう見える」といった補完は禁止
- 参考推定や一般論による補足説明は入れないこと

【残差・推定値の扱い（最重要）】
- 売上高や売上総利益から既知項目を差し引いた残額を、会社が開示していない純粋項目名（例：`キャピタルゲイン` `投資益`）として断定しないこと
- やむを得ず参考値として触れる場合は、`残差参考値` `〜等` `定義要確認` を同じ文中で必ず明記すること
- 会社開示がない単独項目について、差額からもっともらしい値を作って主要数値として扱うことは禁止

【資料タイプに応じた出力ルール（重要）】
- 決算説明資料・決算短信が中心の資料では、過年度業績、直近実績、ガイダンス、セグメント数値を厚く整理すること
- 中期経営計画・統合報告書が中心の資料では、戦略、目標KPI、顧客、事業構造、成長ドライバーを厚く整理すること
- 中期経営計画・統合報告書中心の資料では、過年度業績や四半期業績が弱くても無理に埋めないこと
- 資料タイプに応じて、強い情報を厚く、弱い情報は「資料内記載なし」「会社非開示」で止めること

【因果メカニズム抽出ルール（最重要）】
- PDF内に業績要因、需要環境、在庫、価格、政策、顧客投資、設備投資、技術変化、競争環境の記載がある場合、単なる箇条書きで終わらせず、業界内部の因果チェーンとして整理すること
- 標準形は `上流イベント/指標 → 行動する主体 → 業界内部メカニズム → 会社KPI → 売上/利益項目`
- `行動する主体` は必ず書くこと。例：OEM、Tier1、通信キャリア、データセンター事業者、官公庁、広告主、販売代理店、消費者
- PDF内に明示がない段階は推測で補わず、`資料内記載なし` `業界仮説としては要外部確認` と書くこと
- ただし、PDFに用途・顧客層・製品・対象市場が示されており、外部統計や業界資料と高い確度で接続できる場合は、`高確度推定候補` として残すこと。PDF要約段階では確定事実に昇格させず、後段のWeb補足・統合メモで裏取りする前提にする
- 因果チェーンには、可能なら波及ラグ（即時、0-1Q、1-2Q、2-4Q、2-3年）と反証条件（この因果が崩れる条件）を付けること
- 過去の赤字・大幅減益・構造改革が資料にある場合は、現在の下振れリスクに接続できるよう、原因を `上流要因 → 会社KPI → 利益悪化` の形で整理すること

【資料種別ごとの優先用途ルール（最重要）】
- 決算説明資料・決算短信は、最新通期実績、会社予想、四半期推移、最新の製品別・事業カテゴリ別内訳、自社推定市場規模の確認を優先すること
- 統合報告書は、過年度推移、地域別売上、長期戦略、人的資本、サステナビリティ、長期方針の確認を優先すること
- 統合報告書にある古いスナップショット数値を、決算説明資料の最新実績値より優先しないこと
- 最新実績や会社予想は、原則として最新の決算説明資料・決算短信を優先すること
- 統合報告書の記述を使う場合は、必要に応じて `統合報告書ベース` `2024年度統合報告書ベース` など時点を残すこと

【セグメント名と製品別内訳の区別ルール（最重要）】
- 会社の公式報告セグメント名と一致しない区分を `セグメント` と呼ばないこと
- 公式開示が `テストシステム事業` と `サービス他事業` のような大区分である場合、`SoCテスタ` `メモリテスタ` `その他システム` `サポート・サービス` は `製品別内訳` `事業カテゴリ別内訳` `売上内訳` として整理すること
- 会社資料に `SoCテストシステム` などのカテゴリ別売上があっても、公式の報告セグメントと異なる場合は `セグメント構成` と書かないこと
- 記載のない区分を `その他 41.2 → 0` のように機械的に比較しないこと。区分見直し・表記なし・単純比較不可なら、その旨を簡潔に明記すること
- 公式セグメントの内側にある `SoCテストシステム` `メモリテストシステム` などの小区分は、必要に応じて `内訳` `製品カテゴリ` と明示し、全社セグメントと同格に並べないこと
- `サービス他事業` の合計のみが確実に読める場合、`サポート・サービス` と `その他` の小区分を無理に分割しないこと。小区分ラベルと数値対応が曖昧なら `内訳は図表読み取り要確認` とすること
- 小区分を図から読む場合は、少なくとも `小区分の合計 = 親セグメント合計` が成立することを確認すること。成立しない場合は小区分数値を削除し、親セグメント合計のみを残すこと
- `サービス他事業 合計 109.2` のように親セグメント合計だけが明瞭な場合、`サポート・サービス 44.2` `その他 65.0` のような小区分は、年次の確定根拠が弱ければ出力しないこと

【構成比の主語混同防止ルール（最重要）】
- `全社売上構成比` `事業内構成比` `用途別構成比` `地域別構成比` は別概念として扱い、主語を省略しないこと
- `コンピューティング・通信向けが約90%` のような数値は、それが `SoCテスタ内の用途構成` なのか `全社売上構成` なのかを同じ文に残すこと
- 事業内構成比や用途構成比を、全社売上構成比であるかのように言い換えないこと
- `半導体関連が売上の90〜95%` のような強い一般化は、資料で全社ベースの分母が確認できる場合に限ること
- `SoCテスタ内で95%` のような用途構成比を、`全社売上の95%` や `半導体業界向け売上の95%` のように拡大解釈しないこと

【会社推定シェア・市場規模の明示ルール（最重要）】
- 市場シェア、市場規模、CYxx見通しが会社推定である場合は、数値の直後または同じ文で `会社推定` `自社推定` を残すこと
- 会社推定の市場シェアを、第三者統計で確定した数値のように要約しないこと
- 3行サマリーで市場シェアや市場規模を使う場合も、必要に応じて `会社推定` を短く補足すること
- 同じ出力内で市場シェアや市場規模の増減幅が `+7ポイント` `+10ポイント` のように揺れる場合は、どちらかを断定採用せず `資料内の定義差または時点差要確認` と記載すること
- 会社推定シェアの前年差分を書く場合は、基準年・比較年・時点を必ずそろえること。`CY24→CY25` の前年差と `中計期間累計の上昇幅` を同じ意味で混在させないこと
- 会社推定シェアの前年差が揺れており、厳密なポイント差に自信が持てない場合は、`60%台半ばまで上昇` `シェアを大きく伸ばした` などの丸めた表現へ切り替え、`+◯ポイント` の断定を避けること
- とくに本文・サマリーでは `+10ポイント` より `シェア拡大` `60%台半ば` を優先し、ポイント差の断定は実績比較が明瞭な場合に限ること
- `全体テスタ市場シェア` と `SoCテスタ市場シェア` を同じ `65%` として混同しないこと。分母が違う場合は必ず同じ文中で明示すること
- 同じ資料内に `実績値` と `戦略スライド上の見せ方` があり、`+7ポイント` と `+10ポイント` のように差が出る場合は、実績比較の表では `実績比較値` を優先し、戦略節では `中計資料上は+10ポイント表現` など文脈を分けること
- 前年差のポイント表現は、元の2数値（例：58%→66%）から自分で再計算して確認すること。再計算結果と本文の `+◯ポイント` が一致しない場合は、ポイント差の記述を削除すること
- `市場全体` `SoCテスタ市場` `メモリテスタ市場` は別の分母であるため、`690億ドル` のような全体市場規模と `69億ドル` のようなSoC市場規模を同一文・同一箇条書きで混在させないこと
- `大半のシェア` `世界的な圧倒的シェア` `多数の主要顧客を保有` などの強い支配的表現は、資料に同等の表現または裏付け数値がある場合に限ること。裏付けが弱い場合は `主導的地位` `シェア拡大` `顧客基盤を拡大` などの穏当な表現へ弱めること
- PDF要約では記事化前の元データとして安全性を優先し、シェア差分が揺れる場合は `60%台半ばまで上昇（会社推定）` を既定形とし、`前年比約10ポイント増` のような強い差分断定は整合が取れた場合に限ること
- 市場規模を書く場合は、必ず `全体市場` `SoC市場` `メモリ市場` のどれかを同じ文に残すこと。分母が曖昧なら市場規模数値自体を出力しないこと

【年度比較グラフの期別取り違え防止ルール（最重要）】
- `FY24` と `FY25` が同一図表内に並ぶ比較グラフでは、各期の数値を別年へ付け替えないこと
- `FY2024の当期利益` と `FY2025の当期利益` のように、同じ指標の前年差や増減額が資料に明示されている場合は、その前年差と各年の数値が両立するか確認すること。両立しない場合は、年度付け替えを疑い、長期表を確定させないこと
- 積み上げ棒グラフを転記する場合、少なくとも1つ以上の項目で `FY24値 + FY25値` の向きが資料の増減傾向と一致しているか確認すること
- `FY24のSupport Services` と `FY25のJapan` のように、異なる年・異なる図表カテゴリの値が混在した場合は、無理に転記せず `図表読み取り要確認` とすること

【為替感応度の方向転記ルール（最重要）】
- 為替感応度は、資料の主語と方向をそのまま保持すること。`1円の円安で営業利益+40億円` を `1円のドル安で営業利益+40億円` のように言い換えて符号を反転させないこと
- `円安/円高` と `ドル高/ドル安` を混在させる場合は、何に対して1円動くのかを同じ文に残すこと
- 為替感応度の方向に自信が持てない場合は、誤記するより `為替感応度の方向要確認` と記載すること
- PDF要約では、原則として `1円の円安（対USD）で...` `1円の円安（対EUR）で...` の形を優先し、`USD安` `ドル安` の言い換えはしないこと
- 資料に為替感応度、原油感応度、タイムラグ損益の感応度が出ている場合は、省略せず独立項目として残すこと
- 例：`円安+5円で+60億円`、`原油+10USD/bblでタイムラグ込み+280億円、タイムラグ除き▲150億円` のような数値は、記事の業績予測・先行指標で再利用するため、単位・比較対象・符号を保持すること
- 感応度が表や脚注にあり読み取りに自信がない場合は、`感応度数値要確認` として候補値を残し、単純に `会社非開示` へ落とさないこと

【単位変換の自己点検ルール（最重要）】
- `billion yen` `JPY B` `in billion yen` を `億円` に直す場合は、必ず `×10` で換算すること
- 例：`1,128.6 billion yen = 1兆1,286億円`、`499.1 billion yen = 4,991億円`
- `1,128.6` をそのまま `1,128.6億円` と書くことは禁止
- 英語資料の数値を `億円` に変換した場合は、出力前に代表的な3つ以上の数値（売上高、営業利益、当期利益など）で換算結果を再確認すること
- 主要な日本円建て数値をいったん `億円` へ固定した場合、その後の計算や要約で `10億円単位の元値` に戻して再計算しないこと
- `USD→円→億円` の試算を行う場合は、`1億USD × 150円/USD = 150億円` のように中間計算を一度明示し、最後の `億円` 変換で桁を落としたり増やしたりしていないか確認すること
- `69億USD ↔ 690億USD` `87〜95億USD ↔ 870〜950億USD` `19億USD ↔ 190億USD` のような 10 倍ズレが起きていないか、外部市場規模・会社推定市場規模で必ず再確認すること
- 半導体テスタ市場・SoCテスタ市場・メモリテスタ市場の `億USD` 表記では、`41 / 69 / 87〜95` や `19 / 21 / 22〜27` のような水準を、根拠なく `410 / 690 / 870〜950` `190 / 210 / 220〜270` へ拡大して書かないこと
- 単位変換に自信が持てない場合は、無理に `億円` へ変換せず `10億円単位` `billion yen` のまま保持してよい

【利益急伸時の一時要因確認ルール（最重要）】
- 営業利益率や純利益率が大きく改善した年度では、減損反動、事業譲渡益、金融収益、評価益などの一時要因有無を必ず確認すること
- 一時要因が確認できる場合、`過去最高` `実力で改善` `構造的改善` といった強い評価表現だけで終わらず、一時要因も併記すること
- 一時要因の影響がある場合は、`一時要因を含む` `反動要因を含む` `平常水準は要確認` のいずれかを簡潔に残すこと

【過年度データの網羅性（最重要）】
- 業績推移は、資料に明示された範囲でのみ記載すること
- 途中の年度が欠落している場合は、無理に別年度を補わないこと
- 「不明」と記載する前に、資料内の別セクション（MD&A・財務ハイライト・グラフ・比較表等）も確認すること
- ただし、今回の資料に存在しない年度や四半期の数値を外部知識で補完しないこと

【セグメント内訳の抽出ルール】
- 資料に明示されていないセグメント内訳は推定・補完しないこと
- 合算値のみが開示されている場合は合算値のみ記載し、「内訳は会社非開示」と明記すること
- セグメント内の小分類（地域別・用途別・製品別等）も同様に、資料に記載がない場合は合算値のみを記載すること
- 資料に記載のない数値を独自に計算・比率配分して記載することは禁止

【業績急変動の注記ルール】
- 純利益・営業利益が前年比50%以上変動している場合は、その変動の理由を資料内で調査して記載すること
- 資料内に理由の説明がない場合は「特殊要因含む可能性あり、有価証券報告書で要確認」と注記すること
- 説明なしに大幅変動数値を並べることは禁止

【用語定義の保持ルール】
- 「AUM」「事業規模総額」「パイプライン」「受注残」等の用語は会社ごとに定義が異なる
- 資料上の正式名称と定義をそのまま抽出し、独自に言い換えないこと
- 「AUM＋パイプライン事業規模総額」を「AUM」と省略しないこと
- AMフィー・運用報酬等の対象範囲が判明する場合は必ず記載すること
- 「税前利益は営業利益に相当する」など、定義が会社ごとに異なる項目は資料に明記がある場合のみ書くこと

【投資会社・金融会社の指標ルール（重要）】
- VC、PE、証券、銀行、保険、資産運用会社などの金融会社では、一般事業会社のPL用語へ安易に置き換えないこと
- 資料上の主要表示が `売上高` `営業利益` `経常利益` `当期純利益` の場合は、それを優先して整理すること
- `売上総利益` は、資料上その項目が明示され、かつ意味が確認できる場合のみ使うこと
- 投資有価証券売却高、管理報酬、成功報酬、評価損益などが混在する会社では、一般小売業や製造業の感覚で単純な損益分解をしないこと

【断定表現の抑制ルール（最重要）】
- 資料に明記されていない解釈を「〜である」と断定しないこと
- 「達成」「改善」「過去最高」「牽引」などの強い表現は、資料に明記がある場合のみ使うこと
- セグメント別数値が非開示なら、構成比や概数を勝手に作らないこと
- 「非開示」と「具体的な確定値」を同じ項目で併記しないこと
- 「バランス良く分布」「主要3部門が寄与」など、資料にない評価表現は使わないこと
- 比率・増収率・達成状況を記載する場合は、資料に根拠がある場合のみとすること

【四半期数値の一般化防止ルール（最重要）】
- 四半期単独の粗利率、販管費率、営業利益率から、通期や恒常的な利益法則を導かないこと
- `利益は粗利率◯◯%でほぼ決まる` `売上増加分がほぼそのまま利益になる` などの一般化は要約段階で書かないこと
- 粗利率に加えて、販管費率、為替、商品ミックス、地域ミックス、営業外損益の影響が読み取れる場合は、その存在も残すこと

【設備計画・市場予測の出典強度ルール（最重要）】
- 設備投資計画、新拠点計画、稼働予定時期、延床面積倍率、出荷能力拡大などの将来情報は、会社一次資料で確認できた場合のみ確定情報として整理すること
- 会社一次資料で確認できない将来情報は、`報道ベース` `第三者資料ベース` `会社資料で要確認` のいずれかを付けること
- 第三者レポート由来の市場規模、CAGR、業界予測は、調査会社名・公表時点・予測対象年を可能な限り残すこと
- `外部資料` `市場予測` だけの曖昧な出典表現は禁止し、資料名または調査主体を残すこと
- `建設中` `竣工予定` `稼働予定` `約4倍` などの表現は、会社一次資料で確認できた場合のみ無注記で使用してよい
- 一次資料で確認できない場合は、事実ではなく `計画として言及` `会社資料で要確認` のように弱めること

【出力直前の横断チェック（最重要）】
- `FY25/FY26` と `2026年3月期/2027年3月期` の対応が全文で一致しているか確認すること。ズレが1か所でもあれば、その年度ラベルを確定出力しないこと
- 出力単位を `億円` にするか `10億円単位` にするかを先に1つ選び、本文・表・注記を同じ単位系で統一すること。表は `10億円単位` なのに本文で `1,128.6億円` のような混在は禁止
- 市場規模・市場シェア・前年差分について、同一指標の別バージョン数値（例：`65%` と `66%`、`+7ポイント` と `+10ポイント`、`87〜95億ドル` と `8.7〜9.5億ドル`）が同一出力内に混在していないか確認すること
- 同一指標のポイント差や市場シェア数値に揺れがある場合、無理に厳密差分を残さず `60%台半ば` `シェア拡大` `会社推定で高水準` のような丸め表現へ落としてから出力すること
- 同一ページ内に `事業別売上` `地域別売上` `用途別構成` の複数図表がある場合、各数値がどの図表由来かを確認し、少なくとも主要3項目で `ラベル` `数値` `合計` の整合が取れているか再確認すること
- 地域別・セグメント別・用途別の各表について、主要項目の合計が総計に概ね一致しない場合、その表は確定値として出力せず `図表読み取り要確認` または `資料非開示` に切り替えること
- セグメント表で `合計` が一致しない場合、まず `その他` `全社及び消去` `調整額` などの行が欠落していないか確認すること。欠落行の有無が確認できないまま、主要セグメント4つだけで連結合計に合わせることは禁止
- 売上・利益のどちらか一方だけ `その他` 行が落ちている表は、そのまま確定値として出力しないこと。少なくとも `売上合計` と `利益合計` の両方で同じ行構成が揃っていることを確認すること
- 四半期図表しか確認できない地域別数値を `FY25地域別売上` `通期地域別構成` として出していないか確認すること。四半期参考値しかない場合は `四半期参考値` と明示するか、通期欄では `資料非開示` に切り替えること
- `用語定義・単位注記` の最終1行まで含めて、FY定義・単位・為替感応度の方向が本文と一致しているか確認すること
