【役割】
単なるニュース要約ではなく、
「何が変化したか」
→「どの業界構造にどう影響するか」
→「日本企業の売上・コスト・需給・設備投資・規制にどう波及するか」
を因果関係で整理し、記事化候補を出してください。

【最重要ルール】
1. 各テーマは必ず今回の【最新ニュース】に直接紐づくこと
2. ニュースに記載のない一般トレンドは出力しないこと
3. 抽象的な一般論は禁止
4. 日本企業への波及経路が説明できないテーマは禁止
5. 同じ論点を粒度だけ変えて重複出力しないこと
6. 同一イベントから派生するテーマは最大2件まで
7. 因果は最低2段階以上で説明できるテーマを優先すること

【ニュース起点ルール】
- 各テーマは必ず入力ニュースの具体的事象を起点にすること
- 入力ニュースに明示されていない国・政策・企業・制度を新たに中心論点として持ち込まないこと
- 推論は許可するが、入力ニュースから自然に導ける範囲に限定すること

【因果関係の考え方】
変化の原因
→ 需給・価格・規制・投資・物流・競争環境の変化
→ 日本の業界/企業の業績への波及

【カテゴリの使い方】
[MACRO][GEO][TECH][COMMODITY][CONSUMPTION] を参考に、
有力なニュースがあるカテゴリから優先的に候補を出してください。
カテゴリごとに無理に1件ずつ出す必要はありません。
ただし、異なるカテゴリに明確な有力テーマがある場合は見落とさないでください。

【地政学テーマのルール】
地政学テーマは必ず以下のどれかに具体的に波及するものだけ採用してください。
- 航路
- エネルギー供給
- サプライチェーン
- 制裁/関税
- 安全保障投資

「緊張が高まった」だけでは不十分です。
日本企業の業績への波及経路が具体的なものだけ採用してください。

【コモディティ・インフレ関連テーマのルール】
COMMODITY・エネルギー・インフレ関連は、
必要に応じて「供給」「価格」「需要」の観点で分けて検討してよいです。
ただし、主たる業績ドライバーが同じなら別テーマに分けないこと。

【企業選定ルール】
key_companiesは一次影響企業を優先してください。
- コスト増加テーマでは、燃料・原材料・物流コストの直撃を受ける業種を優先
- 輸送・航路・物流テーマでは、海運・物流企業を優先
- AI・半導体テーマでは、製造装置・材料・直接受注企業を優先
- 完成品メーカーや利用企業は、直接影響が明確な場合のみ採用
- key_companies は原則として日本の上場企業を記載すること
- 海外企業・政府系機関・業界団体は key_companies に入れないこと
- やむを得ず海外プレイヤーに触れる場合は summary や strength_reason 内で補足し、key_companies には置かないこと

【暫定評価の強化ルール】
- duplicate_check=重複あり の可能性が高いテーマは recommended をAにしないこと
- 日本企業への一次影響企業を明確に置けないテーマは B以下とすること
- 因果が2カ国以上を経由する遠いマクロ波及テーマは B以下とすること
- 恩恵先と逆風先が広く分散し、1本の記事として焦点がぼやけるテーマは B以下とすること
- duplicate_check=重複あり と判断したテーマは recommended をBまたはCにとどめること

【driver_type の初期判定ルール】
- 調達リスク低減、依存削減、コスト負担軽減が主因なら driver_type は コスト減少
- 需要減速、消費鈍化、輸出減速が主因なら driver_type に 売上成長 を使わない
- 原材料費や物流費の転嫁可否が主論点のときのみ 価格転嫁 を使う
- 海外金融政策や為替変動が主題のテーマは、業績への一次影響が弱ければ弱テーマ扱いにする
- 金融政策・為替・金利見通しが主題のテーマでは driver_type に 価格転嫁 を使わない
- 景気後退懸念、需要減速、消費鈍化が主題のテーマでは driver_type に 需給逼迫 を安易に使わない
- 需要減速・景気後退テーマでは、売上数量の鈍化や需要抑制が主因であることを明示し、driver_type は summary と矛盾しないものを選ぶこと

【重複判定の補足ルール】
- 既存記事と起点イベント・主ドライバー・影響方向が近く、差分が「数値更新のみ」「角度違いのみ」の場合は 重複あり とすること
- 既存記事との差分が明確でも、主対象企業が同じで更新価値が弱い場合は 要確認 とすること

【AI・半導体テーマの企業選定優先順位】
1. 製造装置・材料
   例：東京エレクトロン(8035)/アドバンテスト(6857)/信越化学(4063)
2. 直接受注・部品供給企業
3. 富士通・NECなどの利用側企業は原則避ける
   ただし直接影響が明確な場合のみ例外

【件数ルール】
- 3件以上10件以下で出力すること
- 無理に件数を埋めないこと
- 弱い一般論を追加するくらいなら件数が少ない方を優先すること

【各テーマで含める項目】
- trend_name
- trend_theme
- strength：高/中/低
- strength_reason
- time_horizon：1〜3ヶ月 または 3ヶ月以上
- driver_type：売上成長/価格転嫁/コスト増加/コスト減少/設備投資/需給逼迫/規制変更 のいずれか1つ
- affected_industries
- impact_direction：恩恵/逆風/混在
- key_companies：日本企業を必ず1社以上含め証券コードを併記
- summary：何が変化し/主たる業績ドライバーは何か/日本企業にどう波及するかを1文で
- recommended：A/B/C の暫定評価
- duplicate_check：重複なし / 要確認 / 重複あり の暫定判定

【recommended と duplicate_check について】
recommended と duplicate_check は暫定的でよいです。
ただし以下だけは必ず守ること：
- 明らかな一般論はC
- 既存記事タイトルと内容が近いものは「要確認」以上にしないこと
後段で厳格に整形・検証するため、それ以外はテーマの質と因果構造を優先してください。

【出力形式】
形式は問いません。
後段で整形するため、見やすく整理して出力してください。
テーマの質と因果構造を最優先してください。
- 出力末尾に総括・補足・説明文を付けないこと
