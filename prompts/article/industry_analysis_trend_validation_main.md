【driver_typeの修正】
必ず以下から1つだけ選ぶこと：売上成長 / 価格転嫁 / コスト増加 / コスト減少 / 設備投資 / 需給逼迫 / 規制変更
それ以外の語は禁止

driver_typeはsummaryおよびimpact_directionと必ず照合し、以下のルールで修正すること：

・summaryに「受注増加」「売上拡大」「業績改善」が含まれ、impact_direction=恩恵の場合
　→ driver_typeは「売上成長」または「設備投資」のどちらが主因かを判断する
　→ 企業が投資を受ける側（受注・売上が増える）なら「売上成長」を優先する
　→ 企業が自ら投資する側なら「設備投資」を使う

・summaryに「コスト増加」「物流コスト」「燃料費上昇」「供給不確実性」が含まれる場合
　→ driver_typeは「コスト増加」を使う
　→ 地政学リスク・航路リスク・封鎖懸念が主因の場合も「規制変更」ではなく「コスト増加」を使う

・summaryに「価格転嫁できない」「抑制」「圧縮」が含まれ、impact_direction=逆風の場合
　→ driver_typeは「価格転嫁」を使う（価格転嫁できない逆風として解釈）
　→ 「需給逼迫」は日本企業が需給の恩恵を受ける場合のみ使う
