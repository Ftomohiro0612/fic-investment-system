【driver_typeの修正】
必ず以下から1つだけ選ぶこと：売上成長 / 価格転嫁 / コスト増加 / コスト減少 / 設備投資 / 需給逼迫 / 規制変更
それ以外の語は禁止

driver_typeはsummaryおよびimpact_directionと必ず照合し、以下のルールで修正すること：

・summaryに「受注増加」「売上拡大」「業績改善」が含まれ、impact_direction=恩恵の場合
　→ driver_typeは「売上成長」または「設備投資」のどちらが主因かを判断する
　→ 企業が投資を受ける側（受注・売上が増える）なら「売上成長」を優先する
　→ 企業が自ら投資する側なら「設備投資」を使う

・summaryに「コスト増加」「物流コスト」「燃料費上昇」「供給不確実性」が含まれる場合
　→ driver_typeは「コスト増加」を使う
　→ 地政学リスク・航路リスク・封鎖懸念が主因の場合も「規制変更」ではなく「コスト増加」を使う

・summaryに「価格転嫁できない」「抑制」「圧縮」が含まれ、impact_direction=逆風の場合
　→ driver_typeは「価格転嫁」を使う（価格転嫁できない逆風として解釈）
　→ 「需給逼迫」は日本企業が需給の恩恵を受ける場合のみ使う

・driver_type=価格転嫁 は、原材料費や物流費の上昇を製品価格へ転嫁できるかどうかが主論点のときに限定すること
　→ 為替・金利・海外インフレ波及が主論点の場合は「価格転嫁」を使わないこと

・summaryに「調達リスク低減」「依存削減」「コスト低下」「代替素材への切替」が含まれる場合
　→ driver_typeは「コスト減少」を優先すること
　→ 売上増加が主因であることを本文で説明できない限り「売上成長」は使わないこと

・summaryに「円安」「円高」「為替」「金利見送り」「利上げ見送り」が含まれる場合
　→ driver_typeは「売上成長」を原則使わないこと
　→ 日本企業の主因が資金調達コストやコスト負担の変化なら「コスト減少」または「コスト増加」を使うこと
　→ 金融政策をきっかけに企業が自ら投資を増減させる論点が主軸なら「設備投資」を使うこと

・summaryに「供給網分散」「調達戦略見直し」「供給リスク分散」が含まれる場合
　→ 企業の投資増が主軸なら「設備投資」、コスト負担の軽減が主軸なら「コスト減少」を使うこと
　→ 「需給逼迫」は直接の需給タイト化で日本企業が恩恵または制約を受ける場合に限定すること

・driver_typeがsummaryの主たる業績ドライバーと一致しない場合
　→ 必ずsummary側ではなくdriver_typeを修正すること

【key_companiesの修正】

- 必ず日本企業を含める
- 証券コード必須

- 一次影響企業を優先する
