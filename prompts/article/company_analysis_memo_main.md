- `コンピューティング・通信用途が約90%` のような数値は、その分母が `SoCテスタ売上` `テストシステム事業売上` `全社売上` のどれかを同じ文に明記すること
- 用途別構成比を全社売上構成比のように言い換えないこと
- `AI関連が売上の90〜95%` のような要約は、全社ベースの分母が会社資料で確認できる場合に限ること

【会社推定値の明示ルール（最重要）】
- 市場シェア、市場規模、CY見通しなどが会社推定である場合は、数値の直後または同じ文で `会社推定` `自社推定` を明記すること
- 会社推定の市場シェアを、第三者機関の確定統計のように書かないこと
- 同じ指標について `+7ポイント` `+10ポイント` のように資料間または出力内で揺れがある場合は、どちらかを断定採用せず `定義差・時点差要確認` と注記すること
- 会社推定の前年差を書く場合は、`CY24→CY25` `FY24→FY25` `中計開始時→現在` など比較軸を同じ文に残すこと。比較軸が異なる値を同じ前年差として並べないこと

【業種別構成比の過剰一般化防止ルール（最重要）】
- 業種別構成比が全社ベースまたは4Q時点の概数としてのみ示されている場合、日本向け構成比・海外向け構成比に自動展開しないこと
- 資料が `日本・海外とも同一構成比` と明示していない限り、`日本10%、海外10%` のような再配分は禁止
- 業種別構成比が概数である場合は、`参考値` `概数` `4Q時点` を同じ見出しまたは同じ行で明記すること
- `地域別・業種別売上構成比` の見出しで、日本値と海外値を並べる場合は、その比較が資料に明示されていることを確認すること。確認できない場合は `全社業種構成比` または `業種別構成の概数` にとどめること

【地域内構成比の見落とし防止ルール（最重要）】
- `北中南米 36.1% / アジア 41.2% / 欧州・その他 22.7%` のように、地域内構成比が `海外に占める構成比` として資料に明示されている場合は、非開示扱いにしないこと
- `※北中南米、アジア、欧州・その他の構成比は海外に占める構成比` のような脚注がある場合、その定義を数値とセットで残すこと
- 地域内構成比が資料に載っているのに `海外内比率は非開示` と書くことは禁止

【顧客基盤の単位統一ルール（最重要）】
- 約35万社 約35万拠点 約11万社 約110カ国 など、顧客基盤に関する数値は、社数・拠点数・国数を別概念として扱うこと
- 一次資料で 拠点 と書かれている数値を 社 に書き換えないこと
- 定義が揺れる場合は、約35万拠点（会社資料） 約11万社（統合報告書） のように定義付きで併記するか、広い顧客基盤 に弱めること

【設備計画・ガイダンス表現の保守化ルール（最重要）】
- 会社開示に 現在の出荷能力が制約 既存能力がボトルネック などの明示がない場合、新拠点計画を 制約解消 と断定せず、将来の供給能力増強 中長期の出荷体制強化 に弱めること
- 通期ガイダンスの記載がない場合は、資料内に通期ガイダンスの記載なし と書くこと。最新ガイダンス相当 会社は業績予想を公表していないと推認 などの推測表現は禁止

【社数・拠点数・国数の定義混同防止ルール（重要）】
- `顧客数` `取引社数` `導入拠点数` `展開国数` は別概念として扱い、相互に言い換えないこと
- `11万社` と `35万拠点` のように母集団の単位が異なる数値は、同じ意味の数値として統合しないこと
- 複数資料で `社` と `拠点` が混在する場合は、`統合報告書では11万社` `別資料では35万拠点` のように定義差を残すこと

【将来計画・外部資料の出典強度ルール（最重要）】
- 設備投資計画、新拠点計画、稼働予定時期、延床面積倍率、出荷能力拡大計画などの将来情報は、会社一次資料で確認できた場合のみ断定して記載すること
- 会社一次資料で確認できない将来情報は、`報道ベース` `第三者資料ベース` `会社資料で要確認` のいずれかを必ず付けること
- 外部市場データ、市場規模、CAGR、業界予測は、`調査会社名/公表時点/予測対象年` をセットで残すこと
- `外部資料` `市場予測` だけの曖昧な表記は禁止し、最低でも資料名または調査主体を明記すること
- 一次資料未確認の設備計画や第三者予測は、1行サマリー、主要結論、最重要KPIの中心材料にしないこと
- 会社資料と第三者資料で内容が食い違う場合は、会社資料を優先し、第三者資料は補足にとどめること

【参考値・会計ベース混在の整理ルール（最重要）】
- `連結参考値` `単体参考値` `参考構成比` `参考値` などの数値は、確定実績値と同格に扱わないこと
- 参考値を使う場合は、本文・表セル・注記のいずれかで必ず `参考値` `連結参考値` `単体参考値` `会社非開示` を明記すること
- 参考値は1行サマリー、主要KPI、結論部分の中心数値として使わないこと
- 連結実績と単体実績、国内のみと全社合計など、会計ベースや集計範囲が異なる数値を同じ比較表で並べる場合は、列名またはセル内で基準の違いを明記すること
- 基準の異なる数値を同じ表に置くと誤認リスクが高い場合は、無理に1表へ統合せず、表を分けること
- 横並びの複数グラフや複数表から数値を引き継ぐ場合は、まず各図表タイトルを固定し、`地域別売上` `事業別売上` `用途別構成` を混線させないこと
- 積み上げ棒グラフの内訳を本文へ持ち込む前に、色と凡例の対応、および内訳合計と総計の一致を確認すること。一致しない場合は `図表読み取り要確認` と記載すること
- 地域別金額と構成比、セグメント別金額と構成比を併記する場合は、少なくとも主要項目について `金額 ÷ 合計 = 構成比` が概ね一致するか確認すること。不一致なら表のまま断定転記しないこと
- `FY24→FY25` の地域別比較やセグメント別比較では、各年の同一項目を対応づけること。`FY24地域別` と `FY25事業別` のような異表混線は禁止
- 地域別内訳を本文へ持ち込む場合は、主要地域の合計が全社売上または海外売上の総計と概ね一致するか確認すること。不一致なら `図表読み取り要確認` と記載すること

【為替感応度の方向保持ルール（重要）】
- 為替感応度は、資料の原文どおりに `円安でプラス` `円高でマイナス` `ドル高でプラス` などの方向を保持し、主語を入れ替えて反転させないこと
- `1円のドル安で営業利益+40億円` のように、原資料の向きと矛盾する書き換えは禁止
- 方向に自信が持てない場合は、誤記するより `為替感応度の方向要確認` と記載すること

【市場全体指標と会社固有指標の区別ルール（重要）】
- `国内IPO件数` `グロース市場IPO件数` `M&A件数` などの市場全体指標と、企業固有の `IPO EXIT件数` `受注件数` `案件数` は必ず別指標として扱うこと
- 市場全体指標を書く場合は、指標名に必ず対象範囲を明記すること
  例：`国内IPO件数（市場全体）` `東証グロース市場IPO件数` `会社のIPO EXIT件数`
- 市場全体の件数と会社固有の件数を同じ文中で続けて書く場合は、主語と対象範囲を毎回明示し、読者が同一指標と誤認しないようにすること
- 市場全体指標を会社固有の実績のように要約することは禁止
- シナリオや結論で `IPO件数が年10〜20社に回復` のように書く場合は、それが市場全体なのか会社のEXIT件数なのかを必ず明記すること
- 市場全体指標をそのまま会社の売上・利益の予想値へ直結させる場合は、間にある会社固有の変数（会社のEXIT件数、パイプライン、案件数など）を必ず1段挟むこと

【推計・補完なし表現の整合ルール（重要）】
- 参考値、構成比参考、単純試算、残差参考値、筆者推定を本文内で用いた場合は、末尾で `推計・補完は行っていない` と断定しないこと
- 推計や参考値を用いた場合は、`会社非開示項目には参考値や単純試算を含む箇所がある` など、実態に即した簡潔な注記に置き換えること

【目標と現状の比較ルール（重要）】
- 中期経営計画の目標と足元実績を比較する場合は、同じ定義・同じ指標かを必ず確認すること
- 会社が明示していない限り、「前倒し達成」「超過達成」「達成済み」といった強い表現を使わないこと
- 足元実績が目標水準を上回る場合でも、期間差・一時要因・調整後数値の可能性があるときは
  「目標水準を上回る」「目標レンジに到達しているように見える」などの表現にとどめること
- 会社が明示していない限り、「会社目標をクリア」「中計をすでに突破」といった投資判断を強く誘導する表現は使わないこと

【業績予測の書き方】
- 単に「考え方」だけでなく、「現状の指標を踏まえた今後の見通し」を示してください
- ベースケース・上振れシナリオ・下振れシナリオを具体的に書いてください
- 各シナリオで「どんな変化が起こるか」「どんな先行指標がトリガーになるか」を明示してください
- 数値の根拠は外部検索結果やPDF要約から引用してください
- この段階では、粗いレンジや方向感で十分な場合は無理に精密試算しないこと

【過年度データと最新業績の保持】
- PDF要約に過年度の業績推移が含まれていれば、必ず分析メモに残してください
- 売上・営業利益・利益率の3〜5年分を明示してください
- さらに以下を含めてください
  ・直近四半期の単独実績（取得できる場合）
  ・直近四半期までの累計実績（取得できる場合）
  ・通期会社予想（ガイダンス、取得できる場合）
  ・通期予想に対する進捗率（取得できる場合）
- 取得できない項目は1行で「資料非開示」と書けば十分です
- 根拠のない補完推計で空欄を埋めないこと

【過年度業績表の作成ルール】
- 過年度データは取得できた最新年度から遡って3〜5期分を記載すること
- FY2022のデータがあってもFY2023が欠落している場合は、FY2022を省略しFY2024から記載してよい
- 中間年度が欠落したまま表に並べることは禁止
- 同一企業の異なる年度で同一数値が並ぶ場合は「混在の可能性あり、要精査」と注記すること

【出力直前の横断チェック（最重要）】
- `FY25/FY26` と `2026年3月期/2027年3月期` の対応が全文で一致しているか確認すること。`2025年3月期（FY25）` `2026年3月期予想（FY26）` のような誤記が1か所でも残る場合は、その年度ラベルを確定出力しないこと
- 統合メモの単位を `億円` にするか `10億円単位` にするかを先に1つ選び、本文・表・箇条書き・シナリオ・注記を同じ単位系で統一すること
- 同一指標の別バージョン数値（例：`65%` と `66%`、`+7ポイント` と `+10ポイント`、`69億ドル` と `8.7〜9.5億ドル`）が同一メモ内に混在していないか確認すること。混在する場合は時点・比較軸・単位を明記するか `要確認` とすること
- 地域別金額・セグメント別金額・用途別構成比を同時に使う場合は、少なくとも主要項目で `ラベル` `数値` `合計` `構成比` の整合を再確認すること。不一致ならその表または箇条書きは `図表読み取り要確認` とすること
- 為替感応度は、`円安/円高` `ドル高/ドル安` の主語と方向が全文で一貫しているか確認すること。リスク節やシナリオ節だけで符号が反転していないか再確認すること
- `用語定義・単位注記` のFY定義が、冒頭サマリー・業績表・ガイダンス節と完全一致しているか確認すること
- `単位：10億円` で整理する場合は、メモ本文・シナリオ・注記でも `1,128.6億円` のような表記を使わないこと。`億円` に直す場合は全数値を変換し、混在を禁止すること
- PDF要約側で地域別通期数値が未確定または `図表読み取り要確認` の場合、統合メモ側でその値を確定値として昇格させないこと
- `SoCテスタ内の用途構成95%` のような数値を、全社売上構成比や全社顧客構成比として書き換えていないか確認すること
- `全体シェア65%` と `SoCテスタ市場シェア65%` のような分母違いの指標を同一意味で使っていないか確認すること

【数値表現の厳密化ルール】
- 「率」を使う場合は必ず「○○%」と表記し、「ポイント改善」「ポイント悪化」と混同しないこと
- 必ず「率（%）」「額（億円）」「ポイント（p）」を区別すること
- 例：正「粗利率が47.2%→48.1%へ+0.9ポイント改善」

【比率・カバー率の算式固定ルール（重要）】
- 管理報酬カバー率、費用カバー率、利益率などの重要比率は、分子・分母・算式を同じ文または同じ表セルで明記すること
- 分母候補が複数ある場合（例：販管費40億円ベース、事業税除く販管費36億円ベース）は、どの定義を使ったか必ず書くこと
- 異なる定義の比率を同一記事内で混在させないこと
- 同じ指標について複数の定義が資料に存在する場合は、保守的な定義を主文で使い、他の定義は補足に分けること
- `損益分岐点を超える` `キャピタルゲインがゼロでも黒字` などの強い結論に接続する場合は、比率の算式だけでなく、他の収益・費用項目を無視した単純試算であるかを明記すること

【投資会社・金融会社の利益項目ルール（重要）】
- VC、PE、証券、銀行、保険、資産運用会社などの金融会社では、一般事業会社の感覚で `売上総利益` を主軸に説明しないこと
- 資料上の主要表示が `売上高` `営業利益` `経常利益` `当期純利益` である場合は、それを優先して使うこと
- `売上総利益` は、資料にその項目が明示され、意味が確認できる場合のみ使うこと
- 投資有価証券売却高、管理報酬、成功報酬、評価損益、引当金戻入などが混在する会社では、単純な差し引きで営業利益を説明しないこと

【販管費・コスト構造の抽出ルール】
- 販管費の内訳が資料に記載されている場合は抽出すること
- 販管費率の前年比変化と主な増減要因を記載すること
- 記載がない場合は「資料非開示」で十分です

1. 企業概要（簡潔に）
2. 事業セグメントと主要顧客

4. 直近四半期の単独業績

6. 売上の因果構造（最重要）

- 表は重要なものに絞ること
- 同じ論点の繰り返しを避けること
- 最後に記事タイトル・スラッグ・キーワードは出力しないこと
