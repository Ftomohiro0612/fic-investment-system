## 0. 背景

Claude記事作成工程はv4・15章構造（主軸：業界トレンド→ポジション→業績変換→投資判断、補助軸：上流環境マップ4テーマ×4段階）に移行した。これにより、Claudeが消費するCodex投入パックに必要な情報が変わった。この仕様書は、**v4記事の各H2章で必要な情報をCodex側で先に整理して投入パックに含める**ためのチェックリストである。

## 1. 既存セクション（必須・継続）

これらは現状の `claude_input_pack.md` に含まれており、v4でも引き続き必須：

- 基本情報（企業名、コード、事業領域、row番号、作業フォルダ、スラッグ、キーワード）
- 取得済み資料（PDFと抽出テキストへのパス）
- 取得失敗・未取得資料（理由付き）
- 業界トレンド情報（業界判定材料、主要統計URL、競争構造、主要顧客産業）
- 投資家向け論点素材（業界の勝ち筋、業績への変換、次の決算で見るKPI）
- 公開記事で必ず反映する修正方針
- PDF抽出テキストからの確認スニペット

## 2. v4で新設するセクション（必須）

以下の3セクションを新規追加。Codexは決算短信・補足説明資料・統合報告書から組成する。

### 2.1 セグメント別過去3期マトリックス（H2 5 収益構造 用）

**目的**：v4 H2 5「収益構造」をClaudeが即座に書けるよう、セグメント別×過去3期×（売上・営業利益・利益率）を表形式で集計済みにする。

**フォーマット例**：

```markdown
## セグメント別過去3期マトリックス

| セグメント | FY2023売上 | FY2023営業利益 | FY2024売上 | FY2024営業利益 | FY2025売上 | FY2025営業利益 | FY2025利益率 |
|---|---|---|---|---|---|---|---|
| セグメントA | 9,178 | 183 | 9,433 | 197 | ... | ... | ... |
| セグメントB | ... | ... | ... | ... | ... | ... | ... |
| 連結合計 | ... | ... | ... | ... | ... | ... | ... |

注：単位は百万円または億円（会社開示に合わせる）。連結調整・「その他」は別行として残す。
```

**出典**：決算短信のセグメント情報、補足説明資料のセグメント別実績。

| ... | ... | ... | ... | ... | ... | ... | ... | ... |
| FY2025（実績） | ... | ... | ... | ... | ... | ... | ... | ... |
| FY2026（会社予想） | ... | ... | ... | ... | ... | ... | ... | ... |
| FY2027（中計目標） | ... | ... | ... | ... | ... | ... | ... | ... |

## 主要CAGR
- 売上 N年CAGR: +X%
- 営業利益 N年CAGR: +X%
- 純利益 N年CAGR: +X%

**出典**：決算短信、historicaldata資料、有報、統合報告書のフィナンシャルハイライト。

### 2.3 業績ドライバー候補4テーマ案＋画像連動仕様（H2 7 業績ドライバー＋画像WP工程 用）

**目的**：v4 H2 7「業績ドライバー」の補助軸（上流環境マップ4テーマ×4段階）と、画像WP工程の画像作成仕様を同時に渡す。

### テーマ2：（同上）
...

### テーマ3：（同上）
...

### テーマ4：（同上）
...

- 注目リスク：4本（テーマ1〜4の主要リスクから抽出）

### 画像2：投資仮説マップ
- ファイル名予定：`{slug}-investment-thesis-map-ai.png`
- 代替テキスト：`{企業名}（{コード}）投資仮説マップ（業界トレンド→ポジション→業績変換→投資判断）`

**Codexの作業手順**：
1. 決算短信・補足説明資料・統合報告書から業績ドライバー候補をリストアップ
2. 4テーマに集約（多すぎる場合は売上規模・利益寄与度・読者関心で優先順位）
3. 各テーマに①〜④を埋める。④は実績数字＋結論ラベル候補
4. 画像作成仕様（画像1・画像2）も同時に書き、画像WP工程に渡す

## 4. Codex作業フローへの組込み

Codex投入パック作成工程（FIC企業分析01）で、以下の手順を追加する：

1. **既存手順**：PDF取得、テキスト抽出、業界トレンド情報整理、PDF抽出スニペット
2. **v4追加手順**：
   - セグメント別過去3期マトリックスを作成（決算短信・補足説明資料から）
   - 過去5-10期業績推移表＋CAGRを作成（決算短信・historicaldataから）
   - 業績ドライバー候補4テーマ案＋画像連動仕様を作成（決算説明資料・統合報告書から）
   - 同業他社の数値補強（ウェブ検索で最新四半期数値を取得、3〜5社分）
   - 業界の追い風/逆風 各5項目（業界統計・公的資料引用付き）
   - 業界の勝ち筋（KSF）5項目（業界構造から導出）
   - 中計達成ブリッジ素材（中計資料・決算説明資料から組成）
   - 会社予想の前提条件1表（決算説明資料から集約）

## 5. Claude側の利用方針

Claudeは新v4記事を書く際、以下の順で投入パックを参照する：

1. 基本情報を確認
2. 業界トレンド情報＋追い風/逆風＋KSF → H2 1, 3を書く
3. セグメント別過去3期マトリックス → H2 5を書く
4. 過去5-10期業績推移表＋CAGR → H2 6を書く
5. 業績ドライバー候補4テーマ案 → H2 7（補助軸の4テーマ×4段階表）を書く＋画像連動仕様を本文HTMLコメントに転写
6. 中計達成ブリッジ素材 → H2 8を書く
7. 会社予想の前提条件1表 → H2 9（3シナリオ）を書く
8. 同業他社数値 → H2 11を書く
9. 既存セクション（リスク、参照資料）→ H2 12, 14を書く
10. H2 2（投資仮説ティーザー）、H2 13（まとめ）、H2 15（FAQ）はClaude総括で書く
