## Output Format

Return the article in a structured format that is easy to review and publish.

1. SEO title suggestion
2. Meta description suggestion
3. Introduction
4. Summary block
5. Main article body
6. Internal link suggestions

## Main Body Structure
- Beginner layer
- Advanced analysis layer
- Risks and watch points
- Conclusion

## Internal Link Output
List each suggested internal link with:
- target article topic
- why it is relevant
- recommended anchor text
