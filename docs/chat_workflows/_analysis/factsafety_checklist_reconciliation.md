## 確認A: §4「3ラベル」と既存 `factual-handling-rules` の用語突合

### 突合対象
- **Step B §4**: 「会社開示 / 外部推計 / FIC試算」
- **既存 `factual-handling-rules` §6・§9・§11**: 「`会社開示値` / `外部推計` / `FIC前提付き試算（筆者試算/概算シナリオ）`」

### 判定: **(a) 完全一致**（ただしStep B側の表記を既存Skillの正式表記に合わせる）

3区分は実質的に同一概念。差分は表記ゆれのみ:
| Step B提案 | factual-handling-rules（正本） | 採用表記 |
|---|---|---|
| 会社開示 | **会社開示値** | 会社開示値 |
| 外部推計 | **外部推計** | 外部推計（一致） |
| FIC試算 | **FIC前提付き試算（筆者試算/概算シナリオ）** | FIC前提付き試算 |

→ **採用方針: (a)。100点像・writing-style・article-quality-checklist では `factual-handling-rules` の正式表記を正本として参照する**（独自表記を作らない）。

### 重要な補足（fact_safety_consistency_check §3 由来）
出所ラベルは**2系統あり、別軸で併存**する（1つの数値が両方を持ち得る）:
1. **数値の開示/試算ラベル**（factual-handling §6）＝会社開示値 / 外部推計 / FIC前提付き試算
2. **主張・イベントの確度ラベル**（source-hierarchy）＝公式発表 / 会社説明 / 報道 / 調査会社予測 / FIC仮説（強/中/弱）

→ fact_safety_consistency_check の**未決事項#1**「2種類の出所ラベルの対応表を article-quality-checklist 側に1つ置くか」は、Step D（Phase 4）で**置く方向で設計**するのが整合的。

## 確認B: §8「FICらしさ要素」の checklist 項目化可否

各要素を「checklist項目化（判定可能）」「理念条項（writing-style/article-design-principlesへ）」に切り分け。

### 1. 公認会計士の視点 → **一部checklist / 一部理念**
- ✅ checklist化可:
  - 「一時要因と継続要因が区別されているか」（既存 factual §5・checklist と整合）
  - 「設備投資・減価償却・在庫・運転資本の将来収益への影響に言及があるか」
  - 「会社説明と数値の動きの整合に触れているか」
- 🔶 理念条項へ: 「会計士的な解釈の"深さ"そのもの」は定量判定困難 → 理念条項。

### 2. 上流→個別企業の主軸 → **checklist化可（中核項目）**
- ✅ 「業界上流変数→当社KPI→営業利益の波及チェーン（4〜6段）が書かれているか」（既存 checklist#21 を流用・強化）
- ✅ 「市場全体の数字と個別業績の"中間要因"が明示されているか」（編集方針§5）

### 3. 誠実な限界開示 → **一部checklist / 一部理念**
- ✅ checklist化可: 「不明・仮説段階・一般傾向の区別表記があるか」「断定しきれない箇所に留保表現があるか」
- 🔶 理念条項へ: 「知的誠実さ」の姿勢自体は理念。

### 4. 時間軸の明示 → **checklist化可**
- ✅ 「価格転嫁・受注→売上計上のラグに言及があるか」
- ✅ 「一時収益 vs 継続収益の時間軸explainer（初心者box）があるか」（既存 checklist#19 を流用）

### まとめ（落とし込み先）
| 要素 | checklist項目化 | 理念条項 |
|---|---|---|
| 1 会計士視点 | 一時/継続の分離・運転資本言及・説明と数値の整合 | 解釈の深さ |
| 2 上流→個別 | 波及チェーン・中間要因明示 | — |
| 3 誠実な限界開示 | 不明/仮説/一般傾向の区別・留保表現 | 知的誠実さの姿勢 |
| 4 時間軸 | ラグ言及・一時/継続explainer | — |

→ **大半は checklist 化可能**。理念条項は新規 Skill `article-design-principles`（Phase 4成果物2）に集約するのが整合的。
