## 4. Phase 4設計への影響

- Phase 4の主要/補足振り分けは、**実構造（15章）を機械確認せずに**章名を立てていた。特に「業界の風向き」を補足扱いにしていたが、実標準では**第1章（最前）**。新構成3章は読者に判断枠組みを与える独立章で、優先動線の中核。
- **アコーディオン折りたたみ・L1物理/L2L3論理・優先動線**は、公開標準（全章展開・折りたたみ無し）には**まだ無い「前向きの最適化提案」**。100点像のベースは実15章構造とし、その上に最適化を載せる二段で再整理が必要。
- 主要/補足の振り分けは、実15章に対して**引き直す**必要がある（次工程）。
