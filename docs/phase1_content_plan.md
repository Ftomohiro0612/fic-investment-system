# フェーズ1 コンテンツ計画

作成日: 2026-05-22

Status: phase1-content-plan

## 目的

トップページMVP公開後に、読者が迷わず回遊できる最低限の常設記事群を整える。

フェーズ1では、ニュース起点の記事を増やす前に、以下の2カテゴリーをFICの辞書として整備する。

- テーマの読み方
- 投資の読み方

## 役割分担

| 領域 | 担当 | 役割 |
| --- | --- | --- |
| 企業分析 | tomo | 個別企業の業績ドライバー、利益構造、リスクを読む主力記事 |
| テーマ分析 | tomo | ニュース起点で、材料がどの企業・業界に波及するかを読む記事 |
| テーマの読み方 | Codex | 金利、為替、物流費などのテーマを企業KPIに落とす常設解説 |
| 投資の読み方 | Codex | 決算、指標、財務用語を読むための常設基礎講座 |

## アイキャッチ方針

フェーズ1記事は、カテゴリーごとに統一感のあるアイキャッチを使う。

- `テーマの読み方`: 黒ベース、黄色アクセント、抽象的なマーケット・産業モチーフ
- `投資の読み方`: 黒ベース、白い資料・表・数字、黄色アクセント
- 画像内に長い日本語文章は入れない
- 必要な文字は、WordPress側のタイトル表示とOGP文言に任せる
- 既存投稿のアイキャッチは、ユーザー明示なしでは変更しない

詳細は `docs/eyecatch_image_plan.md` にまとめる。
