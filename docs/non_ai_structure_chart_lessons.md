# 非AI構造図の見やすさメモ

業界分析記事で使った非AI構造図のうち、企業分析にも流用できる見やすさの要点をまとめる。

## 参考にするポイント

- 冒頭に「この図で伝えたいこと」を明示する。図表タイトルではなく、読者が持ち帰る結論を書く。
- 大きな結論見出しを濃紺の帯に置き、黄色ラベルで視線を止める。
- 図の中の要素は4つ前後に絞る。要素が多い場合は、本文表に回す。
- 各カードは「番号」「短い見出し」「補足1-2行」の3層にする。
- 矢印で読む順番を固定する。左から右へ、上流要因から業績反映へ流す。
- 下部に「見る順番」または「確認すべき指標」を一行で置く。
- 脚注で図の目的を明示する。例: 「テーマの強さではなく、業績に近い確認指標を整理するための図です。」
- 文字は太く、大きく、余白を広く取る。細かい数値を詰め込まない。
- フォントは太く読める日本語フォントを標準にする。HTML/CSSで作る場合は `"Yu Gothic", "YuGothic", "Meiryo", "Noto Sans JP", Arial, sans-serif` を基本にし、見出しは `font-weight: 900`、カード見出しは `800-900`、本文も `700` 程度を使う。PowerShell/System.DrawingでPNGを作る場合は `Meiryo` を標準にする（`Yu Gothic` は細く見えやすい）。
- 正確な数値比較や比率は、別の表・グラフで扱う。構造図では判断順序と因果関係を優先する。

## 企業分析への応用

企業分析では、以下のような図表に向く。

- 上流環境メインマップ: 原油、為替、需要、政策、地政学などの外部環境を4領域程度に整理する。
- 確認順マップ: 上流環境 → 先行指標 → 会社KPI → 利益項目の順番を示す。
- 成長テーマの実現順: 投資/取得 → 稼働/統合 → 売上/数量 → 利益反映。
- 市況企業の見る順番: 商品価格 → スプレッド/在庫影響 → 稼働率/数量 → 利益。
- 投資仮説マップ: 強気材料とリスクを**並置する2×2（田の字）**で見せる（フローにしない）。リスク（例: 市況反落）を1象限として強気材料と**対等の面積**で置き、楽観一辺倒にしない。フロー型にすると上流環境マップ（確認順の図）と構造が重複し、リスクが末尾に従属するため避ける。

## 避けること

- 表の内容をそのまま画像化する。
- 1枚に6個以上のカードを詰める。
- カード内に長文を入れる。
- 「すごい」「追い風」だけで終わり、どの数字を見るべきか分からない図にする。
- 生成AI画像風の質感に寄せすぎて、文字や順番が読みにくくなる。
- 同じ記事内で複数の図に**同一の型（左→右フロー）を使い回す**（図ごとに役割に合う型を選ぶ。例: 上流環境=フロー／投資仮説=2×2象限）。

## 追補：画像配置原則（L-023・2026-05-24 3861縦ライン検証 FIC実機発見）

構造図／概念図（AI画像）の配置は次の原則に従う（詳細は `docs/ai_image_lessons.md` L-023に集約）：

- **概念図（AI画像）の配置は「章冒頭H2直下（em導入文の後）」を原則**とする。読者がまず視覚で章のメッセージを把握→本文で深掘る流れが画像活用度を最大化。
- **章末配置は読者の画像活用度を下げる**（FIC実機発見・3861パイロットで5図全てを章末配置していたが、テンプレ `wordpress/templates/company_analysis_template.html` のHTMLコメントは「H3直下・章冒頭・ドライバー①直前」を想定していた＝テンプレ非準拠）。
- 詳細は `docs/ai_image_lessons.md`「L-023：画像配置原則」を参照。
