# FIC独自ドライバー選定の規律（L-028）

**位置づけ**：`researcher_company` / `writer` / `reviewer` / `article-quality-checklist` の4ファイルに横断的に影響するドライバー選定規律。**会社開示フレームのなぞり防止**＋**FIC独自分析の組み込み**を担保する独立ガイド。
**初版**＝2026-05-24（3861_oji_v4_pilot 縦ライン1本完成MS1達成後、FIC指摘で発見）。

---

## 1. 基本方針

ドライバー選定は「会社が言ったから」型ではなく「**FIC独自分析**」型で行う。`researcher_company` の出力で「**公式版（会社開示フレーム）**」と「**FIC独自版（複数情報源分析）**」の両方を提示し、`writer` は記事ではFIC独自版を優先採用する（または公式版と並列扱い）。

---

## 2. researcher_company §8 の出力フォーマット（必須・L-028）

### §8-A. 公式ドライバー（会社開示のフレーム）
- T1〜T4：会社中計／セグメント区分／会社感応度に直結したドライバー
- `writer`/`reviewer`/`designer` が継承する場合の標準パターン

### §8-B. FIC独自ドライバー（複数情報源分析・writer選択候補）
4視点候補（**最低1点必須**・**該当する全てを §8-B に列挙し、最終的にどの視点を採用するかは writer の選択裁量**）：

1. **隠れドライバー視点**：公式中計の枠外にある利益要因
2. **分解視点**：会社セグメント区分を別軸で分解
3. **実質比重視点**：会社感応度から逆算した実質ドライバー比重
4. **同業逆算視点**：同業比較から逆算した固有ドライバー（複合要因分解）

各候補に**根拠（複数情報源・FIC試算・確度評価）**を併記。

### §8-C. writer への申し送り
- 記事では §8-B を優先採用するか §8-A と並列扱いするかを writer が判断
- §8-B採用時は記事で「**FIC独自分析**」と明示（FIC意見ラベル併用＝expression-strength-rules §10-3）

### 【writer判断フロー】（必読・FIC確定2026-05-24）

| §8-B視点と§8-A公式版の関係 | writer判断 |
|---|---|
| §8-Bの視点と §8-A が**論理的に独立** | **並列扱い**（記事内で両ドライバーを別章節 or 並列H3で展開） |
| §8-Bの視点が §8-A を**再解釈・補強** | **優先採用**（§8-Aを参考として吸収し、§8-Bを記事の主軸ドライバーとして展開） |
| §8-Bの視点が §8-A と**矛盾** | **reviewer §2継承プロトコルでFIC確認必須項目に昇格・writer単独判断不可** |

## 3. 4視点の解説（3861_oji_v4_pilot 王子HDの実例）

### 視点1：隠れドライバー（公式中計の枠外）
**例**：王子HDの「**資本効率改革の一時要因クラスター**」
- 賃貸不動産売却益400億＋政策保有株売却益348億＋退職給付信託返還益95億 = **約843億**
- 中計2027の4軸（資本効率／ポートフォリオ転換／サステナビリティ／木質バイオマス）の外にあるが、当期純利益+94億の主因
- FIC独自視点：T4を「**T4a継続的（中計2027財務戦略の継続枠）**」と「**T4b一時要因クラスター（剥落予定）**」に分解

**記事内表現例**：
> **FIC評価：T4を T4a と T4b に分解すると、T4b一時要因クラスターは約843億で当期純利益+94億の主因です。中計2027の4軸の枠外にあるため公式ドライバーには現れませんが、FY2027以降の本業（営業利益）回復が同等規模を補えるかが、純利益水準を維持する鍵になります**

### 視点2：分解視点（会社セグメント区分を別軸で分解）
**例**：資源環境ビジネス（単一セグメント）を **CENIBRA(ブラジル)／Pan Pac(NZ)／AustroCel(オーストリア)** の3拠点別に分解
- 為替感応度（BRL/USD vs NZD/USD）・市況感応度・地政学リスクが拠点ごとに異なる
- FIC独自視点：「単一ドライバー扱いは粗い・3拠点分解で為替・地政学リスクを精緻化」

### 視点3：実質比重視点（会社感応度から逆算）
**例**：会社開示感応度比較
- パルプ10USD/t→34.3億 / **チップ10USD/t→46.4億** / 古紙1円/kg→33.7億
- **数字上は「チップ価格変動の感応度が最大」だが、会社の説明では「パルプ市況」が前面**
- FIC独自視点：「実質的にはチップ価格変動も同等以上の影響・要監視」と踏み込む

### 視点4：同業逆算視点（同業比較から逆算した複合要因分解）
**例**：同業比較（営業利益増減率）
- 日本製紙+27.9% / 大王+145% / 北越△61.8% / **王子△48.9%**
- 単に「パルプ垂直統合の差」だけでなく、**複合要因の分解**が必要：
  - 為替感応度の構造的違い（王子はBRL/NZD両方持つ）
  - 中国エクスポージャーの差（江蘇王子製紙）
  - 構造改革タイミングの差

## 4. writer / reviewer / designer の運用

### writer
- `researcher` の §8-A／§8-B の両方を読み、上記§2の **writer判断フロー**で並列／優先採用／FIC確認必須を判定
- §8-B採用時は記事で「**FIC独自分析**」と明示（FIC意見ラベル併用＝`expression-strength-rules` §10-3）
- `claude_review_notes.md` ② FIC確認必須項目に「**ドライバー選定理由（公式 or 独自 or 並列）**」を追記

### reviewer
- 記事のドライバー選定が公式版のなぞりになっていないか点検
- 会社開示の感応度を逆算した実質比重との整合性（例：チップ感応度46.4億 > パルプ34.3億 の場合、ドライバー本数・重要度がそれを反映しているか）
- 3拠点・3事業区分等の分解視点が必要な企業で、単一セグメント区分のままドライバー化していないか

### designer
- §2継承プロトコル（L-009）で**FIC独自ドライバー採用時は概念図にもFIC独自視点を反映**
- 例：投資仮説マップに「公式中計の枠外にある一時要因クラスター」を独立象限として配置

## 7. 業界版L-027運用3階層ガイドライン（2026-05-25追加）

**位置づけ**：業界分析で L-027規律（FIC意見の積極的表出ルール）を運用する3階層ガイドライン。企業分析と業界分析の本質的違い（情報源構造の違い）から派生する規律設計。L-028（FIC独自ドライバー4視点）と近接論点のため、本ドキュメントに §7 として併設。

**初版**＝2026-05-25（researcher_industry 起草前のPhase 0 で FIC が「業界分析はそもそも独自性しかないのか？」を提起し、3階層整理で確定）。

### 7-1. 業界版L-027運用3階層の定義

業界分析の独自性構造（**取得層＝公開情報のみ／統合解釈層＝独自性100%**）を踏まえ、章別に**3階層**で L-027ラベル運用を整理する：

| レベル | 該当箇所 | 公式情報源の有無 | L-027ラベル運用 |
|---|---|---|---|
| **レベルA：公式情報あり** | 業界全体ロードマップ達成可能性（章8）／業績シナリオ判定（章9）／先行指標の数値現在値（章10） | 業界団体ロードマップ・政府計画・主要企業共通開示が存在 | **L-027ラベル必須**（FIC評価／FIC見立て を明示） |
| **レベルB：混在** | 業界の風向き判定（章1）／投資仮説（章2）／競合・代替候補のFIC順位付け（章7）／まとめのFIC意見集約（章12） | 主要企業の開示を業界横断で統合解釈 | **L-027ラベル推奨**（独自性が高い段落のみラベル付け） |
| **レベルC：完全独自** | 影響経路N段階波及（章3）／銘柄分類4区分（章4〜7構造そのもの）／FIC独自4視点（§8-B採用箇所）／3シナリオ下振れ閾値（横串原則） | 公式情報なし・FIC統合解釈100% | **L-027ラベル不要**（記事構造そのものが独自分析として読者に伝わる） |

### 7-2. 各レベルの該当箇所と公式情報源（章別マッピング）

業界版13章ごとに、各章がどのレベルに該当するかを明示：

| 章 | タイトル | レベル | 該当する公式情報源 |
|---|---|---|---|
| 章1 | 業界の風向き（起点イベント+確度4区分） | **B** | 起点イベント＝公式発表／業界全体波及評価＝統合解釈 |
| 章2 | 投資仮説（業界全体） | **B** | 主要企業の戦略開示＋統合解釈 |
| 章3 | 影響経路マップ（N段階波及） | **C** | 公式情報なし・FICサプライチェーン統合分析 |
| 章4 | 直接恩恵候補 | **C** | 銘柄分類構造そのもの＝独自 |
| 章5 | 確認候補 | **C** | 同上 |
| 章6 | 周辺材料 | **C** | 同上 |
| 章7 | 競合・代替候補 | **B〜C** | 競合企業の存在＝公式／順位付け＝独自 |
| **章8** | **業界全体ロードマップと達成可能性検証** | **A** | **業界団体ロードマップ・政府計画あり／達成可能性評価＝FIC** |
| 章9 | 業績シナリオ（3シナリオ） | **A〜B** | 主要企業の業績見通し＝公式／3シナリオ判定＝統合解釈 |
| 章10 | 先行指標と判定基準 | **A** | 現在値＝公式（業界統計・公的データ）／判定基準＝FIC独自 |
| 章11 | リスクシナリオ | **B〜C** | リスク要因＝公式＋独自混在／下振れ閾値＝FIC独自 |
| 章12 | まとめ | **B** | FIC意見集約＝統合解釈 |
| 章13 | 参照資料／FAQ | - | 中立的引用 |

### 7-3. ラベル運用ルール（必須/推奨/不要）

#### レベルA（ラベル必須）
- 公式情報源（業界団体・政府・主要企業共通開示）を引用したうえで、FIC独自評価を**並列で明示**する
- 使用ラベル：**「FIC評価」「FIC見立て」「会計士視点では」**（王子HD MS2と同一ラベル体系・対称設計）
- 例：「業界団体ロードマップでは2030年に〇〇兆円市場と予測（業界団体A 2026年資料）。**FIC評価**では達成可能性は△△の理由でやや慎重に見積もる」
- **重要**：業績シナリオ確率（章9）は**確率付与せず・ベース/上振れ/下振れの定性表現＋根拠注記のみ**（企業版と対称設計＝王子HD企業版で確率付与未実装）

#### レベルB（ラベル推奨）
- 公式情報の引用と統合解釈が混在する章で、**独自性が高い段落のみ**ラベル付け
- 全段落にラベル付けすると冗長化＝独自性メリハリが消える
- 例：「主要企業3社の戦略は◯◯方向で一致（各社IR）。**FIC見立て**では、競合・代替候補の◇◇の存在が中長期で重しになる可能性」

#### レベルC（ラベル不要）
- 記事構造そのものが独自分析として読者に伝わるため、追加ラベル不要
- 例：影響経路N段階波及表（章3）／銘柄分類4区分の章構造（章4〜7）／§8-B採用箇所のFIC独自4視点
- ラベルを付けると「公開情報の引用にラベルを付ける」のと同じ意味で**冗長**

### 7-4. sony-tsmcでの適用例（パイロット完走後に追記）

researcher_industry本作業（sony-tsmc industry_input_pack_v3.md 生成）完走後に、実証データで具体化：
- 章別にどの段落がレベルA/B/Cに該当するか
- レベルA該当段落で実際に使ったラベル（FIC評価／FIC見立て／会計士視点では）
- レベルC該当章で「ラベル不要」と判定した根拠（記事構造が独自分析として機能している証拠）

→ 本セクションはパイロット完走時点で追記（現在は§7-1〜§7-3のみで初版確定）。

### 7-5. 関連と適用範囲

- **適用 subagent**：writer_industry（章別ラベル運用）／reviewer（B-10業界版5論点判定）／article-quality-checklist業界版（B-10判定基準）／designer_industry（概念図キャプションのラベル運用）
- **researcher_industry での扱い**：素材整備段階のため本ガイドラインの直接適用は限定的。ただし §7 後工程準備で「writer_industry が章別ラベル運用できる素材」を整える（公式情報源と独自解釈の区別ラベルを素材段階で付ける）
- **企業版への横展開**：本3階層構造は **企業版にも適用可能**（企業版でも会社開示＝公式情報／FIC評価＝独自分析の区別が必要）。ただし企業版は王子HD MS2で既にラベル運用が定着しているため、業界版で先行実装＋実証→企業版へも横展開を将来検討。
