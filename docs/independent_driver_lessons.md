# FIC独自ドライバー選定の規律（L-028）

**位置づけ**：`researcher_company` / `writer` / `reviewer` / `article-quality-checklist` の4ファイルに横断的に影響するドライバー選定規律。**会社開示フレームのなぞり防止**＋**FIC独自分析の組み込み**を担保する独立ガイド。
**初版**＝2026-05-24（3861_oji_v4_pilot 縦ライン1本完成MS1達成後、FIC指摘で発見）。

---

## 1. 基本方針

ドライバー選定は「会社が言ったから」型ではなく「**FIC独自分析**」型で行う。`researcher_company` の出力で「**公式版（会社開示フレーム）**」と「**FIC独自版（複数情報源分析）**」の両方を提示し、`writer` は記事ではFIC独自版を優先採用する（または公式版と並列扱い）。

---

## 2. researcher_company §8 の出力フォーマット（必須・L-028）

### §8-A. 公式ドライバー（会社開示のフレーム）
- T1〜T4：会社中計／セグメント区分／会社感応度に直結したドライバー
- `writer`/`reviewer`/`designer` が継承する場合の標準パターン

### §8-B. FIC独自ドライバー（複数情報源分析・writer選択候補）
4視点候補（**最低1点必須**・**該当する全てを §8-B に列挙し、最終的にどの視点を採用するかは writer の選択裁量**）：

1. **隠れドライバー視点**：公式中計の枠外にある利益要因
2. **分解視点**：会社セグメント区分を別軸で分解
3. **実質比重視点**：会社感応度から逆算した実質ドライバー比重
4. **同業逆算視点**：同業比較から逆算した固有ドライバー（複合要因分解）

各候補に**根拠（複数情報源・FIC試算・確度評価）**を併記。

### §8-C. writer への申し送り
- 記事では §8-B を優先採用するか §8-A と並列扱いするかを writer が判断
- §8-B採用時は記事で「**FIC独自分析**」と明示（FIC意見ラベル併用＝expression-strength-rules §10-3）

### 【writer判断フロー】（必読・FIC確定2026-05-24）

| §8-B視点と§8-A公式版の関係 | writer判断 |
|---|---|
| §8-Bの視点と §8-A が**論理的に独立** | **並列扱い**（記事内で両ドライバーを別章節 or 並列H3で展開） |
| §8-Bの視点が §8-A を**再解釈・補強** | **優先採用**（§8-Aを参考として吸収し、§8-Bを記事の主軸ドライバーとして展開） |
| §8-Bの視点が §8-A と**矛盾** | **reviewer §2継承プロトコルでFIC確認必須項目に昇格・writer単独判断不可** |

---

## 3. 4視点の解説（3861_oji_v4_pilot 王子HDの実例）

### 視点1：隠れドライバー（公式中計の枠外）
**例**：王子HDの「**資本効率改革の一時要因クラスター**」
- 賃貸不動産売却益400億＋政策保有株売却益348億＋退職給付信託返還益95億 = **約843億**
- 中計2027の4軸（資本効率／ポートフォリオ転換／サステナビリティ／木質バイオマス）の外にあるが、当期純利益+94億の主因
- FIC独自視点：T4を「**T4a継続的（中計2027財務戦略の継続枠）**」と「**T4b一時要因クラスター（剥落予定）**」に分解

**記事内表現例**：
> **FIC評価：T4を T4a と T4b に分解すると、T4b一時要因クラスターは約843億で当期純利益+94億の主因です。中計2027の4軸の枠外にあるため公式ドライバーには現れませんが、FY2027以降の本業（営業利益）回復が同等規模を補えるかが、純利益水準を維持する鍵になります**

### 視点2：分解視点（会社セグメント区分を別軸で分解）
**例**：資源環境ビジネス（単一セグメント）を **CENIBRA(ブラジル)／Pan Pac(NZ)／AustroCel(オーストリア)** の3拠点別に分解
- 為替感応度（BRL/USD vs NZD/USD）・市況感応度・地政学リスクが拠点ごとに異なる
- FIC独自視点：「単一ドライバー扱いは粗い・3拠点分解で為替・地政学リスクを精緻化」

### 視点3：実質比重視点（会社感応度から逆算）
**例**：会社開示感応度比較
- パルプ10USD/t→34.3億 / **チップ10USD/t→46.4億** / 古紙1円/kg→33.7億
- **数字上は「チップ価格変動の感応度が最大」だが、会社の説明では「パルプ市況」が前面**
- FIC独自視点：「実質的にはチップ価格変動も同等以上の影響・要監視」と踏み込む

### 視点4：同業逆算視点（同業比較から逆算した複合要因分解）
**例**：同業比較（営業利益増減率）
- 日本製紙+27.9% / 大王+145% / 北越△61.8% / **王子△48.9%**
- 単に「パルプ垂直統合の差」だけでなく、**複合要因の分解**が必要：
  - 為替感応度の構造的違い（王子はBRL/NZD両方持つ）
  - 中国エクスポージャーの差（江蘇王子製紙）
  - 構造改革タイミングの差

## 4. writer / reviewer / designer の運用

### writer
- `researcher` の §8-A／§8-B の両方を読み、上記§2の **writer判断フロー**で並列／優先採用／FIC確認必須を判定
- §8-B採用時は記事で「**FIC独自分析**」と明示（FIC意見ラベル併用＝`expression-strength-rules` §10-3）
- `claude_review_notes.md` ② FIC確認必須項目に「**ドライバー選定理由（公式 or 独自 or 並列）**」を追記

### reviewer
- 記事のドライバー選定が公式版のなぞりになっていないか点検
- 会社開示の感応度を逆算した実質比重との整合性（例：チップ感応度46.4億 > パルプ34.3億 の場合、ドライバー本数・重要度がそれを反映しているか）
- 3拠点・3事業区分等の分解視点が必要な企業で、単一セグメント区分のままドライバー化していないか

### designer
- §2継承プロトコル（L-009）で**FIC独自ドライバー採用時は概念図にもFIC独自視点を反映**
- 例：投資仮説マップに「公式中計の枠外にある一時要因クラスター」を独立象限として配置
