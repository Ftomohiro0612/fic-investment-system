# 企業分析 参考画像（生成AI概念図）

このフォルダは、企業分析記事の**概念図（AI生成画像）**を作るときの**スタイル・構造の参考**を置く場所です。285Aパイロット（designer・2026-05-22）で生成・§2目視合格した図を昇格させたものです。

## ⚠️ 重要：内容（コンテンツ）を真似しない

- 参考にするのは**型・レイアウト・配色・密度・見出しの強さ・因果フローの見せ方だけ**です。
- **会社名・数値・ドライバー名・象限ラベルは絶対にコピーしない**。記事ごとに、対象企業のデータと **§2 確定ドライバー定義**（本数・統合/分離/除外）をプロンプトで必ず再指定して、ゼロから作り直します。
- 参考画像の内容をそのまま流用すると、別企業の記事に285A（キオクシア）固有の内容が漏れ込み、本文と図が食い違います（読者誤読）。

## 採用条件・不採用条件

- **採用**：画像単体で「伝えたい結論」「読む順／象限の役割」が分かる。本文の §2 ドライバー定義と整合している。
- **不採用**：日本語が崩れた画像／細かすぎて読めない／本文と本数・型・要素が食い違う。
- **数値を正確に読ませるグラフ（構成比・推移）はAI画像にしない**＝静的SVGで作る（`docs/data_figure_lessons.md`）。AI画像は概念図（因果・象限）専用。
