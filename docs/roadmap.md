# Roadmap

## Phase 1: Foundation
- Externalize prompts from Make into repository-managed files
- Define SEO introduction rules
- Document Make inputs and article generation flow
- Start documenting WordPress theme structure

## Phase 2: Article Quality System
- Split prompts into intro, summary, body, CTA, and output format
- Add internal link generation rules
- Add reusable article review checklist
- Establish two-layer article structure for beginner and advanced readers

## Phase 3: WordPress Implementation
- Identify single post template and relevant hooks
- Add reusable intro box and summary box snippets
- Improve related article display and internal link visibility
- Improve spacing, headings, and readability in article templates

## Phase 4: Optimization Loop
- Add A/B testing approach for introductions
- Add SEO review step before publish
- Track high-performing intro patterns and internal link patterns
- Update prompts based on observed search and engagement outcomes
