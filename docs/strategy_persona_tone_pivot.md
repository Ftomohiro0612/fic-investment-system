## 1. 背景・狙い（オーナー合意済みの方向性）

- **読者ペルソナ**：投資を始めたばかり〜2・3年目の個人投資家
- **トーン方針**：**親しみやすい入口 × 信頼できる中身**（平易な言葉で集客し、会計士視点の分析深度で差別化）
- **集客**：X 等 SNS を主要流入として重視（現状 FIC のX フォロワーは約120人＝ほぼ構築前段階）
- **不変のガード**：投資助言・推奨はしない／情報提供に徹する（金商法・charter §6）。砕けても煽り・断定・下ネタには流れない
- **サイト名改称（リブランド）**：別トラックで慎重に検討（本メモの対象外）

## 2. ベンチマーク分析：きお君（@kiokunir）

「キオ君＠ＩＲ資料をアホかわいく要約します」。FIC と同じ一次資料（決算短信・中計・適時開示IR）を、親しみやすく要約して **フォロワー約7.5万（増加中）**。

### なぜ伸びるか（証拠順）
1. **「角度の発見」**＝地味な開示を関心を引くドラマに変換（#8 報酬制度→「株価20倍で報酬枠が足りず改造」で最高70万）。何を主役に立てるかの編集判断が核心
2. **硬い素材 × 軟らかい言葉のギャップ**（意外性→シェア）
3. **擬人化＋キャラ口調**（○○ニキ）＝記憶に残る
4. **1投稿1論点・スクロール耐性**（小まとめ/つづき/総まとめ/結論で要点が拾える）
5. **正確な数字を保持**（保存・信頼される）
6. **一次資料（IR/決算短信）の原本画像を添付**＝検証可能＝信頼の担保
7. **トレンド接続**（生成AI/データセンタ）＋**感情トリガー**

### データの結論
下ネタ投稿（#5=54万）は**最高位ではない**。**ガバナンス・ファイナンスの硬い題材を「角度＋親しみやすさ＋原本画像」で料理した投稿（70万/64万）が最も伸びる**。＝**FIC（会計士視点）の土俵そのもの**。下品さ抜きで同等以上を狙える。

### 集客機構
- アカウント名が機能説明（フォローする理由が一言で伝わる）
- 反復の信頼（毎回同じ型＋IR画像→「この人なら決算が分かる」期待→フォロー）
- 保存性（実用→ブックマーク→再訪）／キャラの顔（指名想起）

## 3. FIC 取り入れ案（取る／変える／取らない）

### 取る（そのまま）
- **一次資料（決算短信・IR）の原本画像/引用を必ず添える**＝ `source-hierarchy`（一次資料優先）の見える化。会計士ブランドと完全整合
- **1投稿1論点・タイトルフック・スクロール構造・1行結論**
- **「角度の発見」**（地味な開示から面白い切り口）＝会計士の解像度で差別化できる最大の勝ち筋
- **擬人化・身近化（工夫3）・言い換え（工夫1）**＝既存 `writing-style` の強化
- **トレンド接続**

### 変える（FIC流に調整）
- スラングは「軽い親しみ」程度に薄める。キャラ口調は可だが信頼レンジ内
- **煽り・断定**（勝ち確/確信歩き/覇権）→ `expression-strength-rules` でトーンダウン。為替・見通しは2段構成
- **一時要因の剥落**（例：為替差益→来期剥落）を下品にせず FIC の分析的強みとして前面化
- **年度・鮮度の正確さ**（`factual-handling-rules`）で、きお君がミスする領域（誤画像・古い資料）を確実に上回る

### 取らない（禁止線）
- 下ネタ・性的innuendo（信頼を破壊）
- 投資助言・売買推奨・断定的な将来約束（金商法／charter §6）
- 事実を超える憶測（特に不祥事系＝名誉毀損リスク）
- 生インプレ/フォロワー数の最大化を目標化すること（KPIの取り違え）

## 4. X と記事の役割分担（両輪）

| | 役割 | 方針 |
|---|---|---|
| **X投稿** | 入口・集客 | きお君型のフック・1論点・親しみやすい言葉・IR原本画像。煽り/下ネタは抜く |
| **記事** | 中身・信頼・回遊先（収益） | タイトル・30秒要約・導入を初心者〜2,3年目に最適化＋「角度の発見」で引き込み。15章の深さ・会計士視点は維持 |

声のトーンは一貫、役割で深さを変える。入口（X）と中身（記事）が断絶すると集客が漏れるため、両輪で更新する。
