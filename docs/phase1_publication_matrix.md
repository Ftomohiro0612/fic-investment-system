# フェーズ1 記事公開対応表

作成日: 2026-05-22

Status: phase1-publication-matrix

## 目的

フェーズ1で作成した常設記事をWordPressへ投入するときに、タイトル、スラッグ、カテゴリ、本文ファイル、アイキャッチ画像を取り違えないようにするための対応表。

## 公開前の共通チェック

- WordPress投稿タイトルは `article_title` を使う。
- 本文はHTMLファイルのコメントメタを除き、本文ブロックを投稿本文へ貼り付ける。
- カテゴリは対応表の `カテゴリ` を使う。
- スラッグは対応表の `スラッグ` を使う。
- アイキャッチは対応表の画像をアップロードして設定する。
- 公開後、該当する企業分析・テーマ分析記事から内部リンクを追加する。

## 公開順の考え方

- まず `投資の読み方` の1から5を公開し、企業分析記事を読むための基礎導線を作る。
- 次に `テーマの読み方` の1から5を公開し、トップページのMarket Triggersと接続する。
- その後、残りの `投資の読み方` と `テーマの読み方` を交互に公開し、内部リンクの受け皿を厚くする。
- 公開後は `/learn/` と `/themes/` の代表リンクを、実際の公開URLに合わせて更新する。
