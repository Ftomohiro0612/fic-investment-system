# 業界横断比較記事 Make シナリオ設計メモ

## 目的

個別企業分析が増えてきたため、同業・近接テーマの複数記事を束ねる「横断比較記事」を Make で生成できるようにする。

狙いは以下の3つ。

- 既存の個別企業分析記事への内部リンクハブを作る
- 「総合商社 比較」「海運 利益構造」「半導体装置 材料 比較」など、比較検索意図を拾う
- GEO向けに、複数企業の違いを1記事で引用しやすい形に整理する

## 想定テーマ例

- 総合商社5社の利益構造比較
- 海運3社の運賃感応度比較
- 鉄道2〜3社の旅客収入・不動産収益比較
- 半導体装置・材料メーカーのAI需要感応度比較
- 電力会社の原子力稼働率・燃料費調整比較
- 証券・金融グループの金利感応度比較

## Makeでの入力項目

最小入力は「書きたいテーマ」だけにする。

推奨入力フィールド:

| 項目 | 必須 | 内容 |
|---|---|---|
| theme | 必須 | 例: `総合商社5社の利益構造比較` |
| target_companies | 任意 | 例: `伊藤忠商事,三菱商事,三井物産,住友商事,丸紅` |
| target_codes | 任意 | 例: `8001,8058,8031,8053,8002` |
| comparison_axis | 任意 | 例: `資源比率,非資源比率,為替感応度,株主還元` |
| article_goal | 任意 | 例: `投資家がどの商社をどう比較すべきか整理する` |
| publish_category | 任意 | 原則 `業界分析` または `企業分析` ではなく比較記事用カテゴリを検討 |

`target_companies` や `target_codes` が空欄の場合は、テーマからClaudeが候補企業を推定する。ただし、推定した企業は本文内で「比較対象として選定」と表現し、事実関係を断定しすぎない。

## 入力元データ

Make側で参照したい情報:

- Google Sheets の企業マスタ
  - 企業名
  - 証券コード
  - 業界タグ
  - 記事URL
  - 最新記事フラグ
  - 主要ドライバー
  - 関連銘柄コード
- 既存記事本文または要約
  - one-liner-summary
  - summary-box
  - 先行指標テーブル
  - リスクテーブル
  - 同業他社比較
- 公式IR資料URL
  - 決算説明資料
  - 中期経営計画
  - 統合報告書

## Makeシナリオ案

1. Webhookまたはフォームでテーマを入力
2. Google Sheetsから企業マスタを検索
3. テーマに合う企業候補を抽出
4. 既存記事URLから必要箇所を取得
5. Claudeに「比較用メモ」を生成させる
6. Claudeに横断比較記事HTMLを生成させる
7. WordPressへ下書き投稿
8. 内部リンク・構造化データ・参照資料を確認

## 内部リンク方針

横断比較記事では、本文中と記事末の両方で個別企業分析へリンクする。

本文中:

- 初出の企業名は `伊藤忠商事（8001）` のように証券コードを併記する
- 既存のPHP自動リンクが効くように、企業名・証券コード表記を崩さない
- 抽象表現だけで済ませない
  - NG: `総合商社大手`
  - OK: `伊藤忠商事（8001）、三菱商事（8058）、三井物産（8031）`

記事末:

```html
<div class="fic-related-companies">
  <p><strong>個別企業分析はこちら</strong></p>
  <div class="fic-related-companies-description">本記事で比較した企業の詳細分析です。</div>
  <ul>
    <li><a href="...">伊藤忠商事（8001）</a></li>
    <li><a href="...">三菱商事（8058）</a></li>
  </ul>
</div>
```

## SEO/GEOルール

- タイトルは「比較」「どこが違うか」「利益構造」「先行指標」を含める
- summary-boxは3文構造にする
- 比較表はAIが引用しやすいよう、1表1論点にする
- 各企業の強み・弱みを断定しすぎず、開示資料に基づく範囲で書く
- 個別企業記事と重複しすぎないよう、横断比較記事では「比較軸」を主役にする
- FAQは以下を基本にする
  - `総合商社5社の利益構造は何が違いますか？`
  - `投資家が比較すべき先行指標は何ですか？`
  - `横断比較で注意すべきリスクは何ですか？`

## 注意点

- 既存個別記事の要約を横断記事に使う場合、古い記事ではなく最新版URLを使う
- `企業別分析（古い記事）` カテゴリの記事は参照対象から除外する
- 企業マスタに記事URLがない企業は、無理にリンクしない
- 数値比較は、会計年度・会計基準・セグメント定義が揃う場合は開示値ベースで行う
- 競合他社の非開示項目がある場合でも、確度の高い推定・レンジ・代理指標で相対感を出せるなら、構造比較だけに逃げずに使う
- 推定値を使う場合は、`推定`、`概算`、`方向感`、`同一基準ではない` などを明記し、精密な実数比較のように断定しない
- 定義差が大きく推定の確度が低い場合は、数値表ではなく `高・中・低`、`大きい・小さい`、`収益感応度の強弱` などの半定量比較に切り替える
- 投資助言表現は禁止
