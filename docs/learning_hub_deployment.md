# 投資の読み方固定ページ 反映手順

作成日: 2026-05-22

## 目的

初心者が企業分析やテーマ分析を読む前に、決算・利益率・受注残・在庫・財務の見方を確認できる中継固定ページを作る。

トップページの文字量を増やさず、「基礎を知りたい人」はこのページへ逃がす。

## 固定ページ本文

学習用の固定ページを作り、本文に以下を入れる。

```text
[fic_learning_hub]
```

推奨ページ名:

```text
投資の読み方
```

推奨スラッグ:

```text
learn
```

## 反映ファイル

- `wordpress/snippets/functions.php`
- `wordpress/snippets/fic-hub-pages.php`
- `wordpress/snippets/fic-learning-hub.php`
- `wordpress/css/custom.css`
- `wordpress/css/fic-home-page-mvp.css`
- `wordpress/previews/fic-learning-hub-preview.html`

Code Snippets で反映する場合は、3つの固定ページハブをまとめた `wordpress/snippets/fic-hub-pages.php` を使う。
`fic-learning-hub.php` はテーマ側 `functions.php` に本体を入れる運用向けの補助ファイル。

## 確認すること

- 指標検索が検索結果へ遷移する
- 投資の読み方、基礎講座、ビギナーガイドの記事数が表示される
- ヒーロー直下の共通ナビから、企業を探す、テーマから探す、投資の読み方へ移動できる
- 決算短信、利益率、受注残・在庫、財務とROE、企業分析の読み順の入口が表示される
- 最新の投資の読み方が表示される
- 企業で試す、材料で試す、トップページへの導線が表示される
- スマホでカードが1列表示になり、文字がはみ出さない

## トップページとの関係

トップページは大きな入口だけを見せ、初心者向けの説明はこの固定ページに集約する。

- トップページ: 第一想起サイトとして、企業・テーマ・学習の入口を提示
- 投資の読み方: 決算や指標の意味を確認する場所
- 企業を探す: 実際の企業分析へ進む場所
- テーマから探す: ニュースや材料から業界・企業への波及を探す場所
