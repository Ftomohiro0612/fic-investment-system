# トップページ公開後 旧導線整理プラン

作成日: 2026-05-22

Status: legacy-cleanup-plan

## 目的

トップページMVPと3つの固定ページハブを公開したあと、旧トップページ・旧カテゴリ導線・サイドバーを段階的に整理する。

いきなり消すのではなく、読者の慣れ、検索流入、内部リンク、回遊データを見ながら下げる。

## 基本方針

- 公開当日は、旧導線を大きく削らない。
- 新しい4入口を主役にし、旧カテゴリ名は補助導線へ下げる。
- `企業分析` は `/companies/` に受け止める。
- `業界分析` は `/themes/` に受け止める。
- 初心者向け説明は `/learn/` に受け止める。
- 決算前後の行動は `/earnings-schedule/` に受け止める。

## 公開当日

目的:

- 新トップと3ハブが壊れていないことを優先する。
- 旧導線は保険として残す。

残す:

- 既存トップページ下部の記事一覧
- 既存サイドバー
- 既存カテゴリ一覧
- 既存の企業分析カテゴリページ
- 既存の業界分析カテゴリページ
- YouTube、About、編集方針

下げる候補:

- ヘッダー/主ナビに `企業分析` と `業界分析` がある場合、表示名をすぐ変えられるなら `企業を探す` / `テーマから探す` へ置き換える。
- ただしリンク先を完全削除せず、カテゴリ一覧はハブ内の「一覧」リンクで残す。

確認:

- トップの4入口が見える。
- 旧トップ本文と新トップMVPが不自然に重複していない。
- サイドバーが新トップの邪魔になっていない。

## 公開3日後

目的:

- 明らかに重複しているトップ本文を整理する。

下げる:

- トップ上部に残っている旧サイト説明文
- 旧カテゴリリンク集
- 新トップの4入口と意味が重なるボタン群
- 旧トップ内の長い説明文

残す:

- 記事一覧
- 決算スケジュール
- サイドバー
- よく読まれている記事

判断基準:

- 新トップのファーストビューが見えているか。
- 旧説明文が新ヒーローのコピーと同じことを言っていないか。
- スマホで最初の画面が長くなりすぎていないか。

## 公開1週間後

目的:

- クリックデータを見て、主導線を確定する。

見るデータ:

- `home_hero_action` の4入口クリック
- `home_firstcheck` のクリック
- `/companies/` から企業分析記事への遷移
- `/themes/` からテーマ分析記事への遷移
- `/learn/` から企業・テーマ記事への遷移
- 検索フォーム、検索チップの利用

下げる候補:

- トップ下部の重複記事一覧
- サイドバーの長いカテゴリ一覧
- ヘッダーの古いカテゴリ名
- クリックされていない補助リンク

残す候補:

- よく読まれている記事
- 決算スケジュール
- About / 編集方針
- YouTube

## 公開2週間後

目的:

- トップページを「第一サイト」らしい入口に寄せ切る。

検討する変更:

- トップ下部の記事一覧を、単なる新着順から「読者の疑問別」へ置き換える。
- サイドバーのカテゴリ一覧を短くする。
- 人気記事を `企業を探す`、`テーマから探す`、`投資の読み方` の3視点で再配置する。
- `投資の読み方` の基礎記事が増えたら、トップ上の学習導線を少し強める。
- 決算予定へのクリックが強い場合、決算予定の説明をトップで少し上げる。

## 整理対象マップ

| 旧要素 | 判断 | 置き換え先 |
| --- | --- | --- |
| ヘッダーの `企業分析` | 主ナビから下げる | `/companies/` |
| ヘッダーの `業界分析` | 主ナビから下げる | `/themes/` |
| トップの旧カテゴリリンク集 | 3日後以降に下げる | トップ4入口 |
| トップの長い説明文 | 新ヒーローと重複する部分を削る | FIC Method / Editorial Policy |
| トップの新着記事一覧 | 重複が強ければ短縮 | Latest Analysis |
| サイドバーのカテゴリ一覧 | 1週間後以降に短縮 | 目的別ハブ |
| よく読まれている記事 | 残す | 将来は疑問別へ再配置 |
| 決算スケジュール | 残す | `/earnings-schedule/` |
| YouTube導線 | 残す | 動画補助導線 |
| About / 編集方針 | 残す | 信頼性導線 |

## やらないこと

- 公開当日に旧カテゴリページを削除しない。
- 公開当日に記事一覧を全削除しない。
- 公開当日にサイドバーを全面撤去しない。
- 検索流入のあるページのURLを変えない。
- `企業分析` / `業界分析` のカテゴリ自体を消さない。

## 次に作るとよいもの

- `/learn/` 用の基礎記事を増やす。
- `/themes/` 内に、金利・為替・半導体・原材料・政策のテーマ別代表リンクを置く。
- `/companies/` 内に、証券コード別・業種別の探し方を追加する。
- 人気記事を「何を知りたいか」別に再分類する。
