# FIC投資研究所 トップページ改修ロードマップ

作成日: 2026-05-22
対象: https://fic-investment.biz/

## 1. 現状認識

トップページは、WordPressテーマ Diver の標準構成を土台に、FIC独自の決算スケジュールカードと記事一覧を追加した状態。
記事本文のCSS、決算スケジュール、サイドバー、SEO/GEO向けの補助スニペットは整備が進んでいる一方、トップページ全体を「FIC投資研究所の入口」として再設計する専用レイヤーはまだ薄い。

公開トップで確認できる主な要素:

- ヘッダー導線: 決算分析スケジュール一覧 / 企業分析 / 業界分析 / YouTube
- ファーストビュー付近: サイト説明文、業界分析のリンク群、直近の分析更新予定
- 中盤: 業界分析記事、記事一覧、企業分析記事の一覧
- サイドバー/下部: よく読まれている記事、プロフィール、四季報導線、YouTube導線、検索、カテゴリー

リポジトリ上の関連実装:

- `wordpress/css/custom.css`: 記事本文、決算スケジュール、サイドバー、関連リンクのCSS
- `wordpress/snippets/functions.php`: 決算スケジュール、トップ用 `[upcoming_earnings]`、一覧ページ用 `[earnings_schedule_table]`、SEO/GEO補助
- `docs/about_page_final.md`: FICのサイト説明・編集体制
- `docs/editorial_policy_final.md`: 編集方針
- `.claude/skills/article-design-principles/SKILL.md`: 記事設計の理想像
- `.claude/skills/writing-style/SKILL.md`: 初心者間口を広げる文体戦略

## 2. 現在地

現在地は「記事単位の品質改善と運用基盤はかなり進んだが、トップページはまだ記事一覧中心のポータル段階」。

できていること:

- FICの分析思想は記事本文、About、編集方針、llms.txt系の記述に存在している。
- 決算スケジュールはショートコード化され、公開済み/更新予定/記事作成予定の状態表示まである。
- 企業分析・業界分析の記事数が増え、トップに並べる素材は十分ある。
- 記事本文の要約・表・注記・関連リンクのデザインは、EY風の黒/黄を軸に整備済み。

不足していること:

- 初見読者が3秒で「このサイトは何をどう読めばよいか」を理解する入口が弱い。
- FIC独自の価値である「上流要因 -> 企業KPI -> 業績への波及」がトップで視覚化されていない。
- 企業分析、業界分析、決算スケジュール、YouTubeの役割分担がトップ上で整理されていない。
- 記事一覧が多く、初心者/精読者/決算追跡者それぞれの導線が混ざっている。
- About/編集方針にある信頼性の説明が、トップでは下部やサイドバーに寄っている。

## 3. 理想イメージ

トップページの理想は「記事の倉庫」ではなく、「投資判断の前提を構造で読むための研究所の入口」。

ファーストビューで伝えるべきこと:

- FIC投資研究所は、株価予想ではなく、企業業績が動く理由を読むサイト。
- 読み方の軸は「上流要因 -> 企業KPI -> 業績 -> 確認すべき指標」。
- 初心者は30秒要約と決算スケジュールから入り、詳しく読みたい人は企業分析/業界分析へ進める。

理想のトップ構成:

1. ヒーロー
   - H1: FIC投資研究所
   - サブコピー: 決算資料と業界指標から、企業業績が動く理由を読む。
   - 4つの入口: 企業を探す / テーマから探す / 投資の読み方 / 決算予定
   - 小さな信頼ラベル: 公開資料ベース / 公認会計士視点 / AI整理 + 人の編集確認

2. FICの読み方
   - 「上流要因 -> 企業KPI -> 業績 -> 監視指標」の4ステップを横並びまたは縦ステップで表示。
   - 例: 原材料価格、為替、設備投資、政策、需要動向などがどの企業に効くかを読む。

3. いま追うべき分析
   - 最新記事を単純な日付順ではなく、企業分析/業界分析/決算更新の3枠に分ける。
   - 各枠に「何が分かる記事か」を短い説明で付ける。

4. 決算分析スケジュール
   - 既存 `[upcoming_earnings]` を活かす。
   - 表示件数と説明文を調整し、「次に更新される記事」導線として使う。

5. 初心者向け入口
   - 「決算の数字だけでなく、なぜ利益が動くかを知りたい方へ」という導線。
   - About/編集方針/ビギナーガイド/代表記事を接続する。

6. YouTube連動
   - テキスト記事を読む時間がない読者向けに、3分前後の図解動画導線を置く。
   - 動画は記事補完であり、トップでは大きくしすぎない。

7. 信頼性と編集方針
   - 下部に、公開資料優先、出典明記、AI利用と人間レビュー、投資助言ではない旨を短くまとめる。
   - 詳細は About / 編集方針へリンク。

## 4. 改修ロードマップ

### Phase 0: 同期と現状固定

目的: 別PC作業との差分を取り込み、現在の公開状態を基準化する。

- `git pull --ff-only` でリモートを同期する。
- トップページ、About、編集方針、決算スケジュールの公開HTMLを保存またはメモ化する。
- 現在トップで使われている固定ページ/ショートコード/ウィジェット/テーマ設定を確認する。

完了条件:

- ローカルが `origin/main` と一致。
- トップページの編集対象が「固定ページ本文」「Diver設定」「functions.php」「追加CSS」のどこか判明。

### Phase 1: トップページ情報設計

目的: 何を上に出し、何を下げるかを決める。

- ファーストビューのコピーを決める。
- 企業分析/業界分析/決算スケジュール/YouTubeの役割を定義する。
- トップで使う記事カードの分類ルールを決める。
- サイドバーに残すもの、トップ本文に移すもの、削るものを分ける。

完了条件:

- トップページのワイヤーフレーム案が1つに絞られている。
- FICの読み方4ステップがトップに入ることが確定。

### Phase 2: 実装方式の決定

目的: WordPress上で安全に反映できる形を決める。

候補:

- 固定ページ本文にHTMLブロックとして実装する。
- `functions.php` にトップ専用ショートコードを追加し、固定ページ側はショートコードだけにする。
- Diverのトップ/ウィジェット設定で一部を組む。

推奨:

- トップ専用ショートコード方式。
- 理由: HTML構造とCSSをリポジトリ管理しやすく、固定ページ本文の手編集事故を減らせる。既存の `[upcoming_earnings]` と相性がよい。

完了条件:

- `fic_home_hero`、`fic_home_reading_flow`、`fic_home_latest_sections` などの分割方針が決まっている。
- CSSのクラス名前空間を `.fic-home-*` に統一する。

### Phase 3: MVP改修

目的: トップの第一印象を変える最小改修を行う。

- ヒーローを追加する。
- FICの読み方4ステップを追加する。
- 既存の直近分析更新予定を、ヒーロー下の主要導線として再配置する。
- 企業を探す / テーマから探す / 投資の読み方 / 決算予定 の4入口を明確化する。
- 既存CSSと競合しない `.fic-home-*` CSSを追加する。

完了条件:

- 初見で「何を読むサイトか」が分かる。
- 既存の記事一覧・決算スケジュールが壊れていない。
- PC/スマホでテキストの折り返しとカード幅が破綻していない。

### Phase 4: 導線最適化

目的: 回遊とSEO/GEOを強める。

- 最新記事一覧を「企業分析」「業界分析」「決算更新」に分ける。
- 代表記事またはよく読まれている記事を、読者の疑問別に再分類する。
- About/編集方針への信頼導線をトップ下部に短く置く。
- YouTube導線を「動画で見る」枠として追加する。
- Category一覧の露出を調整し、古いカテゴリや未分類の見え方を整える。

完了条件:

- 読者が目的別に記事へ進める。
- 生成AI/検索エンジンにも、サイトの専門領域と編集方針が生HTMLで伝わる。

### Phase 5: 計測と改善

目的: 見た目だけでなく、実際の回遊改善を確認する。

- GA4/Search Consoleでトップから企業分析/業界分析/決算スケジュールへの遷移を見る。
- クリックされない枠を下げ、読まれる入口を上げる。
- ヒーローコピー、4入口、決算スケジュール表示件数を調整する。

完了条件:

- トップ直帰率、記事一覧への遷移、決算スケジュールクリックの改善を確認。
- 改修ルールを `docs/workflow_notes.md` または専用メモに追記する。

## 5. 優先順位

最優先:

1. ヒーローでFICの価値を明文化する。
2. 「上流要因 -> 企業KPI -> 業績 -> 監視指標」をトップに出す。
3. 企業を探す / テーマから探す / 投資の読み方 / 決算予定 の4入口を整理する。

次点:

4. 最新記事の分類表示。
5. About/編集方針/YouTube導線の再配置。
6. 人気記事・カテゴリ・サイドバーの整理。

後回し:

7. 大規模なテーマ改修。
8. トップ専用の複雑な動的記事抽出。
9. 完全なビジュアル刷新。

## 6. 次の一手

次にやるべきことは Phase 1 と Phase 2。

具体的には、トップページのワイヤーフレームを1案作り、実装方式を「トップ専用ショートコード + `.fic-home-*` CSS」で確定する。
その後、MVPとしてヒーロー、FICの読み方4ステップ、4入口、既存 `[upcoming_earnings]` の再配置までを小さく実装する。

## 9. 固定ページハブ化

2026-05-22 に、トップページの下に目的別の中継固定ページを置く方針で実装を開始。

追加したハブ:

- 企業を探す: `[fic_company_hub]`
  - 企業名、証券コード、最新企業分析、決算予定から個別企業へ進む入口。
  - 推奨スラッグ: `companies`
- テーマから探す: `[fic_theme_hub]`
  - 金利、為替、原材料、AI、政策、エネルギーなどの材料から業界・企業への波及を探す入口。
  - 推奨スラッグ: `themes`
- 投資の読み方: `[fic_learning_hub]`
  - 決算短信、利益率、受注残、在庫、財務など、企業分析を読む前の基礎を確認する入口。
  - 推奨スラッグ: `learn`

狙い:

- トップページに情報を詰め込みすぎず、初見では大きな入口だけを見せる。
- 読者が「企業名から探す」「ニュース材料から探す」「学習から入る」を選べる状態にする。
- 初心者向けの説明をトップページから分離し、文字量の圧迫感を抑える。

トップページ側の反映:

- ヒーローの主CTAは `companies` 固定ページへ誘導する。
- First Check、Start Here、Reading Route の主要導線は、カテゴリ一覧ではなく `companies` / `themes` / `learn` の各固定ページへ誘導する。
- Latest Analysis の「もっと見る」は、記事一覧としての役割が明確なためカテゴリ一覧への導線を残す。
- 各固定ページハブのヒーロー直下に共通ナビを置き、`companies` / `themes` / `learn` を相互に行き来できるようにする。
- WordPress の Code Snippets へ反映しやすいよう、3ハブをまとめた `wordpress/snippets/fic-hub-pages.php` を用意する。
- トップページの圧迫感を下げるため、Use Cases と Reader Paths はトップから外し、固定ページハブ側へ役割を移す。
- ヘッダー/メニューは `企業を探す` / `テーマから探す` / `投資の読み方` / `決算予定` を基本構成にし、旧カテゴリ名の直リンクは主ナビから下げる。
- トップ下部に `動画でざっくり見る` 枠を追加し、YouTube は記事理解の補助導線として扱う。
