# expression-strength-rules（表現強度・禁止表現ルール）

FICの記事は「公表資料より強く書かない」が大原則。安全性は、確度ラベル・時間軸・先行指標・反証条件で担保し、
**強い形容や断定で見栄えを作らない**。このSkillは、語調・断定・誇張の許容線と、禁止表現→代替表現の対応を定める。

- 情報の出所・信頼度は [[source-hierarchy]]、数値の精度（単位/年度/±50%注記/セグメント推定）は [[factual-handling-rules]]。
- 初心者向けの「親しみやすさ」は [[writing-style]]。本Skillは**誇張・過大断定の抑制**を担い、writing-styleの平易化と両立する（平易にしても強くしない）。

---

## 使い方（いつ・どの役員が参照するか）

| 役員 | 参照する具体的タイミング | 省略してはいけない理由 |
|---|---|---|
| `writer` | ・形容/結論を書くとき<br>・強い動詞（始まった/転換した/確定した）を使う前<br>・タイトル案を作るとき<br>・為替/シェア/供給/中計の言い回しを書くとき | 公式より強い断定は、ファクトが正しくても「誇張記事」になり信頼性を損なう。後段で全タイトル・全結論の手戻りになる |
| `reviewer` | ・公開前ゲートで、過大表現・公式より強い断定・**タイトルと本文のズレ**・一時要因の伏せを検出するとき | 公開後の「煽り」印象は訂正困難。SEO/GEOと読者信頼の双方を毀損する。**最後の防壁**で省略不可 |
| `x_writer` | ・投稿文の煽り/茶化し/強断定/勝ち組負け組表現をチェックするとき | Xは拡散力が高く、煽り表現は炎上・信頼毀損のリスクが本文より大きい |
| `videographer` | ・台本/テロップで誇張表現や内部事情露出を避けるとき | 動画は受動視聴で断定が強く刺さる。誇張は視聴者の誤投資判断を招く |

> **ファクト規律は3段で各々invoke**（researcher予防 → writer確認 → reviewer最終ゲート）。語調は特に「書き手は強く書きがち」なので、writerの自己抑制とreviewerの客観ゲートは別観点の防御層。重複ではない（フェーズ4 6-1）。

## 1. 過大・誇張表現の禁止リストと代替

資料根拠がない限り、左を使わず右に弱める。

| 禁止/注意表現 | 代替表現 | 条件 |
|---|---|---|
| 崩壊 / 崩壊水準 | 事業構造的な収益力低下が顕在化 | — |
| V字回復 | 会社予想ベースでの回復見通し | — |
| 圧倒的 / 圧倒的シェア | 主導的地位 / シェア拡大 | 一次資料でシェア率が確認できる場合のみ具体率を使う |
| 独占 / 世界で唯一 / 競合なし | 事実上の独占的地位 / 供給企業が限られる / 参入障壁が高い | 一次資料で明記がある場合のみ「独占」可 |
| 大半のシェア / 多数の主要顧客を保有 | シェア拡大 / 顧客基盤拡大 | 数値根拠があれば具体率・分母・時点で書く |
| 直撃 / ○○直撃 | 影響を受ける / 影響が及ぶ | — |
| 急騰 / 急落 / 暴落 | 大幅上昇 / 大幅下落（時点・幅を併記） | — |

「過去最高」「急拡大」「実力で改善」だけで済ませず、一時要因（減損反動・事業譲渡益・評価益）がある場合は**併記**する（→ 一時要因の判定は [[factual-handling-rules]]）。

## 2. 公式発表より強い断定の抑制（動詞・確度）

正式受注・契約・供給関係・サプライヤー選定・JV参加などの確認材料がない限り、左を右に弱める。

| 強い断定 | 弱めた表現 |
|---|---|
| 始まった / 転換した / 確定した | 可能性がある / 確認候補 / 正式発表を待つ |
| 恩恵を受ける / 直接恩恵 | 確認候補 / 高関連候補 / 受注確認待ち |
| （関連銘柄を）直接恩恵と断定 | `直接恩恵` は公式受注/契約/供給/JV確認時のみ。未確認は `確認候補` |

確度ラベル（`公式発表`/`会社説明`/`報道ベース`/`調査会社予測`/`FIC仮説`）を崩さない（区分は [[source-hierarchy]]）。

---

## 3. タイトルと本文の強度整合

- **タイトルの強度を本文の慎重さに合わせる**。本文で「一部・一時的・段階的・全面ではない」と弱めているのに、タイトルだけ強くしない。
  - 例: 本文「一部受注方法の見合わせ・生産継続」なのにタイトル「停止拡大」「危機」→ `工期遅延` `粗利率圧迫` `確認ポイント` に寄せる。
- タイトルは検索意図に近づけつつ、公式発表より強い断定にしない。

---

## 4. 為替・市況・業績見通しの2段構成ルール（FIC独自価値の核）

数値や前提（為替・市況・業績見通し・シェア・設備投資）を扱うときは、原則**2段構成**で書く。
「会社前提に置き換える」のではなく、「**会社前提を客観基準として明示**したうえで、**FIC独自の追加視点も書く**」。
これは会計士・税理士視点で「会社発表を読み解く力」を読者に提供する、FIC独自価値の核。

### 段階1: 会社前提・会社開示を客観基準として明示（必須）

- 会社が公表している業績予想・為替前提・市況前提・シェア等を**基準として明示**する。
- 例:「会社は決算説明資料でドル円120円を前提に2027年3月期業績を予想している」。
- 出典は会社IR資料（決算説明資料・有報・中計等）を付ける（→ 出所の質は [[source-hierarchy]]）。

### 段階2: FIC独自視点を補足（会社前提と実勢に乖離がある場合のみ）

会社前提と直近の実勢に乖離があるとき、FIC独自の見解を補足する。数値は試算なら `FIC試算` を明記（→ [[factual-handling-rules]] §6）。

- **為替**: 「会社前提120円に対し、足元150円。感応度（1円＝±5億円）から通期150円なら**+150億円のアップサイド（FIC試算）**」。
- **業績**: 「会社予想は営業利益+10%。ただし第1Q進捗20%で**下期偏重の可能性**」。
- **シェア**: 「会社開示では首位。ただし第2位の新製品投入で**順位逆転リスク**」。
- **設備投資**: 「3年1,000億円の計画。第1Q進捗50%で**年度内達成は微妙**」。

### 禁止（段階1が抜けた雑表現）

段階1（会社前提の明示）や客観基準を欠いた、主語不明の相対表現を使わない。

- `円高反転` `円安進行` — 何（会社前提）に対してかが無い
- `想定よりプラス` `想定より弱含み` — **誰の想定か不明**
- `足元の追い風` `逆風`（客観基準なしの単独使用） — 基準が無い

（「円安/円高」と「ドル高/ドル安」を混在させない、符号整合は [[factual-handling-rules]] §4）

### シェア・市況の具体（2段構成に内包）

- **シェア**: 会社開示/業界統計でシェア率があるのに `国内No.1` `業界大手` の定性だけにしない。段階1で具体率・分母・時点を示し、揺れる場合は断定せず丸め（数値整合は [[factual-handling-rules]]）。段階2で順位逆転リスク等を補足。
- **市況**: 1行サマリー・主要結論では保守表現を優先（誇張の起点になりやすい）。独自試算は段階2で `FIC試算` 明記。

### なぜ2段構成か

- FICの読者は、四季報や会社発表だけでは満足しない。「**会社発表を読み解く力**」がFICの独自価値。
- 段階1（客観基準）＋段階2（FIC視点）で、**信頼性と独自性を両立**する。会計士・税理士視点ならではの精度感を出す。

## 5. 供給制約テーマの表現（途絶ではなく価格/納期）

- 政府・業界団体・企業が供給継続・在庫・代替調達・段階的再開を説明している場合、「**供給途絶**」ではなく「**価格・中間材・納期・価格転嫁**」の問題として書く。
- 企業公式が `受注方法の一時見合わせ` `生産・出荷は継続` `段階的再開` と説明しているなら、`受注停止` `供給停止` `全面停止` の短縮表現で危機感を強めない。**公式文言に近い言い換え**を使う。

---

## 6. 中期経営計画・業績の表現

- 会社が明示していない限り `前倒し達成` `超過達成` `達成済み` `中計をすでに突破` を使わない。
- 足元実績が目標を上回って見える場合でも、期間差・一時要因・調整後数値の可能性があるときは `目標水準を上回る` `目標レンジに到達しているように見える` にとどめる。

---

## 7. 媒体別の語調

- **X投稿**（x_writer）: 強いネットスラング・銘柄を茶化す/煽る表現を避ける。`利益を割り振る` `勝ち組・負け組` などの煽り表現は禁止。本文より少しカジュアルは可だが、断定の強さは本文と同基準。
- **動画**（videographer）: 台本・テロップで誇張表現を使わない。`非AIグラフ` `AI生成図` などの**制作側の内部事情を視聴者向けに出さない**。
- 初心者向けの平易化（「つまり」「ざっくり言うと」）は [[writing-style]] の役割。**平易にすることと強く断定することは別**。平易化しても強度は上げない。

---

## 8. 確度ラベル・出典との接続

- 強い表現を使ってよいのは「一次資料で確認できる場合」。確認できないものは弱める。
- 表現の根拠となる出典の質は [[source-hierarchy]]、数値の扱い（単位・年度・±50%・推定禁止）は [[factual-handling-rules]] を必ず併用する。

---

## 9. なぜこのルールがあるか（事故事例）

- **タイトルと本文のズレ**: 本文が「一部・生産継続」なのにタイトルが「停止拡大」になり、読者に過度な危機感を与える型（`docs/codex_industry_analysis_migration_spec.md` / industry_04 レビュー注意）。
- **為替の雑表現**: `円高反転` `円安進行` を会社前提と無関係に使い、感応度の意味がぶれる（company_03 セルフチェック）。
- **アナリスト・誇張由来の強語**: `圧倒的` `独占` `V字回復` `TSMC直撃` を資料根拠なく使う（company_03 推奨grepの検出対象）。
  → いずれも「ファクトは合っていても表現が強すぎる」事故。語調は数値とは別の防御が要る。

## 10. セルフチェック（公開前 / レビュー時）

- [ ] `崩壊 / 圧倒的 / 独占 / V字回復 / 直撃 / 急騰` 等の強語に一次資料根拠があるか（なければ代替表現へ）
- [ ] `始まった / 転換した / 確定した / 直接恩恵` を、公式確認なしに使っていないか
- [ ] タイトルの強度が本文の慎重さ（一部/一時的/段階的/全面でない）とズレていないか
- [ ] 為替/市況/業績見通しが**2段構成**か：段階1（会社前提＋出典）を明示し、段階2のFIC視点は会社前提との乖離を客観的に示し、試算は `FIC試算` 明記。`円高反転/円安進行/想定より/足元の追い風` など段階1欠落の雑表現が無いか
- [ ] 供給制約を「途絶」と短縮せず、価格/納期/価格転嫁の問題として書いているか
- [ ] 中計の `前倒し達成/超過達成/突破` を会社明示なしに使っていないか
- [ ] X投稿に煽り/茶化し/勝ち組負け組、動画に内部事情露出がないか
- [ ] 「過去最高/急拡大」に一時要因の併記があるか
